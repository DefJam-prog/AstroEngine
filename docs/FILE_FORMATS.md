# Astro Scene v1

`*.astro-scene` — UTF-8 текстовый формат текущей редакторской модели сцены.

```text
ASTRO_SCENE 1
SCENE <scene-id> "<quoted scene name>"
ENTITY <entity-id> <parent-id-or-0> "<quoted entity name>"
END
```

Строки имён кодируются средствами `std::quoted`; Unicode сохраняется в UTF-8. Каждая сцена имеет ненулевой ID, каждая сущность — уникальный ненулевой ID, родитель должен существовать, циклы запрещены. Загрузка ограничивает размер файла 16 MiB и количество сущностей 100000; неизвестная версия, повреждённый UTF-8, неверная структура, лишние записи и ошибки иерархии возвращают диагностику. До успешной полной проверки загруженные данные не заменяют активную модель.

Сохранение пишет временный файл рядом с целевым и затем заменяет целевой файл атомарной операцией платформы (Windows `MoveFileExW` с replace/write-through). Восстановление после аварийного завершения, резервные копии, миграции схем, checksum и гарантия долговечности на всех файловых системах не реализованы.

Формат сохраняет только Scene/Entity ID, имена и parent-child связи. Компоненты, Transform, ресурсы, редакторские UI-состояния и игровой прогресс не входят в v1. Это не формат Save System.
