# Шаблоны игр — конструктор нового проекта

Статус: требования пользователя из раздела 08. Шаблоны и конструктор ещё не реализованы. Не создавать шаблоны, пока не реализованы необходимые им подсистемы.

## Общий контракт

Каждый шаблон создаёт минимальную работающую игру, которую можно менять через редактор и Codex. Каждый шаблон сопровождается инструкцией и автоматическими smoke-тестами. Описание шаблона или набор заглушек не считается работающей игрой.

Редактирование следует единому Command API из [ARCHITECTURE.md](ARCHITECTURE.md). Сохранение прогресса подчиняется явному выбору профиля/правил из [SAVE_SYSTEM.md](SAVE_SYSTEM.md).

## Модульность

Оружие можно отключить, сохранив FPS-контроллер. Камеры и системы управления переиспользуются между жанрами. Шаблоны используют общие компоненты и подсистемы; конкретная структура пакетов и правила комплектации пока не определены.

## Условия реализации и приёмки

- Перед реализацией конкретного шаблона определить и проверить необходимые подсистемы из [GAME_SYSTEMS.md](GAME_SYSTEMS.md) и других архитектурных требований.
- Созданный проект должен запускаться как минимальная работающая игра с заявленным для шаблона составом.
- Инструкция должна объяснять запуск, управление и изменение игры через редактор и Codex.
- Автоматические smoke-тесты должны проверять создание/запуск проекта и основной игровой сценарий соответствующего шаблона. Конкретные сценарии и команды запуска тестов определяются в назначенном подэтапе реализации.
- Для модульности FPS проверить, что отключение оружия сохраняет работоспособность контроллера.
- Работоспособность подтверждается фактическими результатами проверок; наличие этого каталога не подтверждает готовность шаблонов.

Распределение работ задано в [ROADMAP.md](ROADMAP.md): первые 2D-шаблоны — 06.5, продвинутые контроллеры и шаблоны — этап 08. Все шаблоны ожидают реализации необходимых подсистем и явного назначения соответствующего подэтапа. Новые внешние зависимости этим документом не выбираются.
