# Язык редактора

В Windows Editor доступны английский и русский интерфейс. Настройка находится в меню **Edit → Settings… → Language**. Выберите **Русский** и нажмите **Apply**; **Cancel** закрывает окно без применения чернового выбора. Язык применяется сразу и сохраняется отдельно для текущего пользователя. При отсутствии настроек используется English.

Отдельный SDL Game UI demo также содержит настройку **Language** на главном меню или экране паузы. Выбор сохраняется отдельно для текущего пользователя в `game-ui-settings.cfg`, применяется при следующем запуске и не попадает в проект или игровые сохранения. Доступны English и Русский; главный экран, пауза, настройки, HUD-подписи и известные сообщения Game UI переводятся.

Файлы настроек находятся в каталоге пользовательских данных, который возвращает SDL для приложения `AstroEngine` (обычно `%APPDATA%\AstroEngine\AstroEngine\`). `editor-settings.cfg` имеет заголовок `ASTRO_EDITOR_SETTINGS 1`; `game-ui-settings.cfg` — `ASTRO_GAME_UI_SETTINGS 1`. В обоих форматах хранится одна строка `LANGUAGE en|ru`. Запись идёт через временный файл и атомарную замену. Настройки не меняют проект и игровые ресурсы.

Русский шрифт загружается из системного Segoe UI, с Arial как запасным вариантом. Шрифты не копируются в проект. Для корректного отображения кириллицы требуется один из этих шрифтов в Windows.

Каталоги переводов покрывают пользовательские подписи, меню, окна и подсказки Editor и Game UI demo. Неизвестная диагностическая строка сохраняется без изменения, но получает русскую метку «Ошибка редактора» или «Ошибка игры». Поэтому встроенное пояснение SDL/драйвера/операционной системы и ошибки внешнего backend могут остаться на английском. Имена проектов, сцен, сущностей, ассетов, значения HUD и пользовательский текст сохраняются как заданы.

Unit-тесты проверяют русские переводы прямых строк UI Editor, каталог Game UI, известные ошибки, выбор кода языка и поведение неизвестной диагностики. Smoke-тест Editor открывает Settings на русском, а визуальный smoke Game UI переключает Language на Русский и обратно. Runtime demo сохраняет английский вид без изменений по эталонному снимку. Тесты не меняют пользовательский файл настроек.
