## 07.2cb — оценка material color-space contract (assessment complete)

Решено сохранять смысл значений по material/texture role, без дублирующего serialized `ColorSpace` поля. Khronos glTF определяет linear `baseColorFactor`/`COLOR_0` multiplier, sRGB baseColorTexture RGB и linear alpha. В BGFX коде найдено несогласованное выполнение: CPU заранее декодирует image и умножает factor в linear BGRA8, ресурс загружается как обычный BGRA8, затем lit textured shader снова sRGB-декодирует выборку; unlit path передаёт CPU-linear значения напрямую. End-to-end оттенки на mid-tone test пока не измерялись. Runtime не изменён; см. [отчёт 07.2cb](reports/07.2cb-material-color-space-contract.md). ## 07.2bs — mipmapped opaque base-color в Runtime BGFX (implemented prototype)

Для opaque project/source glTF base-color materials Runtime adapter генерирует цепочку общим `prepareLinearBaseColorMipChainBgra8`, создаёт mip-enabled BGRA8 texture и ставит все уровни на upload через BGFX `updateTexture2D`. Cache budget считает всю цепочку, а ключ разделяет no-mip и mip resources; sampler flags используют `selectBaseColorMinFilter`. Runtime Game View smoke требует два texture entries, один mip entry и отдельно 64+ красных/голубых pixels. Full Windows x64/D3D11 Release CTest: **103 passed, 1 skipped из 104 за 166,40 с**. Ограничения: opaque/base-color/UV0/identity transform; smoke визуально прогоняет только source `LINEAR_MIPMAP_LINEAR`; BGFX `updateTexture2D` не сообщает асинхронный per-level upload status. Alpha/PBR/UV extensions и другие backends остаются fallback. [Отчёт](reports/07.2bs-runtime-bgfx-mipmap.md).

## 07.2br — оценка mip-фильтрации Runtime BGFX (assessment complete)

Следующий отдельный подэтап должен ограничиться opaque base-color и четырьмя sampler modes с mip; полный chain должен учитываться в GPU cache budget, ошибки level upload должны освобождать временные GPU resources, а BGFX capability/fallback проверяться на D3D11. MASK/BLEND, другие карты и UV extensions не включать. Baseline: Release build no-op; выбранный CTest **7/7**. Полную регрессию не повторяли, код не менялся. ## 07.1b — bounded glTF/GLB static mesh import (implemented prototype)

The opt-in `astro_gltf` module uses pinned fastgltf v1.0.1, simdjson 5.1.0 and simdutf 9.3.3 from the ignored local `build/07.1b-deps` cache; configure verifies the parser commit and helper-source SHA-256 values, and explicitly disables fastgltf downloads. `GltfImporter::importFile` accepts project-relative `.gltf`/`.glb` files under `Assets/`, imports static triangle POSITION data and optional indices, and writes a checksummed geometry cache under `Library/Derived/gltf`. ## 04.21 — C# metadata batches и отчёты (implemented)
