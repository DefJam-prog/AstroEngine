## Реализация

Добавлен выключенный по умолчанию `ASTRO_BUILD_STACK_SPIKE`; без явного `-DASTRO_BUILD_STACK_SPIKE=ON` headless-приложение не тянет графические библиотеки. Spike находится в `samples/stack_spike/`, создаёт SDL3 окно, инициализирует bgfx D3D11, рендерит ImGui docking и цветной треугольник; отдельная панель проверяет ввод мыши/клавиатуры и изменение размера. `--smoke` завершает опыт после 90 кадров и возвращает ошибку, если не подтверждены docking, ввод, resize и draw calls. Добавлен `stack_spike.smoke`.

Локальный кеш зависимостей (игнорируется Git): `build/spike-deps/`. Ревизии:

| Зависимость | Ревизия |
| --- | --- |
| SDL | `ff70564e57ae23b59ba57b55795f62c2f7a2f357` (source CMake project reports SDL 3.5.0) |
| bgfx | `eebf5686a8c5f1c77e1af2dad17b5746ba17da8f` |
| bx | `57548da89a07771c5b0f8a6711149be70e08a329` |
| bimg | `22177183239e18d7af603e6915156371cc38d18d` |
| Dear ImGui docking | `cf53467ab0db7a783f04b32dd9160e6aa5b720ef` (`1.93.1 WIP`) |

bgfx сгенерирован GENie для VS2022 и собран Debug x64 через MSBuild. Рендерер spike принудительно D3D11, без fallback. Dear ImGui использует официальный SDL3 platform backend; backend renderer реализован локальным адаптером поверх bgfx, встроенных DXBC shader headers bgfx и RGBA font atlas.

Лицензии основных источников: SDL zlib, bgfx/bx/bimg BSD 2-Clause, Dear ImGui MIT. Это не полный аудит транзитивного дерева: bimg/bgfx содержат дополнительные сторонние исходники с отдельными лицензиями (ASTC encoder, dav1d/libavif и другие), хотя spike не использует полный набор этих форматов. Для распространения нужна отдельная инвентаризация фактически включённых библиотек и уведомлений.

- Чистая базовая конфигурация/сборка: `cmake -S . -B build/baseline-00.3 -G Ninja -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON` и `cmake --build build/baseline-00.3` — успешно на MSVC x64.
- Базовый CTest: **3/3 passed** (startup/help/invalid).
- bgfx Debug x64 dependency build: MSBuild solution, exit 0; bgfx, bx, bimgDebug библиотеки получены.
- Spike: конфигурация `cmake -S . -B build/stack-spike -G Ninja -DCMAKE_BUILD_TYPE=Debug -DASTRO_BUILD_STACK_SPIKE=ON -DBUILD_TESTING=ON` — успешно.
- Spike compilation: `cmake --build build/stack-spike --parallel 4` — exit 0.
- Полный CTest spike-конфигурации: **4/4 passed**, включая `stack_spike.smoke` (2.61 s); общая длительность 2.95 s. Smoke сообщил `frames=90 docked=1 keys=1 clicks=0 resized=1 rendered=1`.
- Приложение вручную запускалось и продолжительно рендерило. Снятый stdout: `SDL 3005000; ImGui 1.93.1 WIP; renderer Direct3D 11`, `frames=18409 docked=1 keys=12 clicks=16 resized=0 rendered=1`. Resize вручную не зарегистрирован, однако resize проверяется автоматическим smoke.

## Проблемы и ограничения

Сборочные команды и тесты прошли. Полноценное визуальное ручное осматривание/перетаскивание панелей через UI автоматизацию не удалось подтвердить; docking и отрисовка подтверждены кодовыми проверками и запуском, поэтому UX/визуальный вид не объявляются полностью проверенными. Клавиатурный smoke подтверждён синтетическим SDL event. Прототип Windows x64/MSVC/D3D11; другие платформы и graphics backends не проверялись.

Dear ImGui сообщается upstream как `1.93.1 WIP`; ревизии всех зависимостей зафиксированы только для воспроизводимости spike и не являются финальным выбором движка. Успешный spike подтверждает базовую совместимость этих конкретных исходников и Windows toolchain, не функциональную полноту или поддержку production. Размер итогового exe: примерно 19.1 MB Debug; это не измерение Release или runtime package. CMake 4.4.4 standalone и Ninja 1.13.2 установлены, но фактическая сборка шла встроенными VS CMake/Ninja 3.31.6/1.12.1.

Инструменты установлены по явному разрешению; исходники зависимостей загружены только в локальный игнорируемый build-кеш. Пользовательские исходники и ресурсы не удалялись/не перезаписывались. Коммит после checkpoint и GitHub push не выполнялись. Следующий этап 01 не начинался.
