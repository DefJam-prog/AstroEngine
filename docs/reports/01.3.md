# Отчёт подэтапа 01.3

Дата: 2026-11-13. Объём: EventBus, TimeService/fixed timestep и tick модулей. Подэтапы после 01.3 не начаты.

## Исходное состояние

Git: ветка `main`, последний коммит `fc16987 Checkpoint before 00.3: requirements and build foundation`. До изменений в дереве уже находились незакоммиченные результаты 00.3 и 01.1–01.2; они сохранены. До правок `cmake --build build/stack-spike --parallel 4` завершился без пересборки, CTest — 5/5 passed.

Проверенная среда: Visual Studio 2022 Build Tools 17.14.45 Developer Command Prompt x64, MSVC 19.44.35230, CMake 3.31.6, Ninja 1.12.1, Windows SDK 10.0.26100.0. CTest запускается из VS Developer Command Prompt, так как в обычном PowerShell он отсутствует в PATH.

## Изменения

- `engine/core/include/astro/core/EventBus.hpp`: header-only typed EventBus, subscription IDs, синхронная публикация, snapshot-поведение при subscribe/unsubscribe в callback, обработка исключений callback.
- `engine/core/include/astro/core/TimeService.hpp`, `engine/core/src/TimeService.cpp`: конфигурация fixed delta/clamp/catch-up, frame timing и interpolation alpha, учёт отброшенного времени, pause, валидация нечисловых и отрицательных delta.
- `IEngineModule.hpp`, `ModuleRegistry.hpp/.cpp`: добавлен `tick(fixedDelta)`; вызовы идут в порядке инициализации, ошибки возвращаются вызывающему коду с именем модуля.
- `engine/core/CMakeLists.txt`, `tests/unit/core/CoreTests.cpp`: подключён TimeService и добавлены unit-проверки EventBus, времени, fixed tick и error paths.
- Обновлены README, ARCHITECTURE, ROADMAP, STATUS, DECISIONS, TESTING, BUILD_GUIDE и добавлен этот отчёт.

Пример цикла: `timing = time.advance(frameDelta)`; затем вызвать `registry.tick(timing.fixedDeltaSeconds)` ровно `timing.fixedStepCount` раз. Интерполяционный alpha доступен отображающему слою. EventBus не потокобезопасен. При tick error автоматический shutdown не запускается: владелец цикла обрабатывает ошибку и вызывает shutdown.

Integration тесты команд/сериализации пока неприменимы: эти подсистемы ещё не реализованы. Smoke теста отдельного runtime-loop пока нет; tick покрыт unit-тестом. Проверки графических эталонов и производительности не относятся к реализованным в этом подэтапе функциям.

## Известные ограничения

- EventBus рассчитан на один поток; concurrent subscribe/publish/unsubscribe не синхронизированы.
- Тип события определяется C++ типом, события межпроцессно не сериализуются.
- TimeService получает delta извне, аппаратные часы и wall-clock сервис здесь не реализованы.
- При достижении catch-up cap целые избыточные шаги отбрасываются и учитываются; дробный остаток сохраняется для следующего frame.
- Пауза очищает текущий дробный accumulator; simulation time не растёт.
- `ModuleRegistry::tick` возвращает ошибку без автоматического shutdown; вызывающая сторона отвечает за политику остановки.

Рекомендуемый следующий подэтап: **01.4 — CommandRegistry, schema, validation и execute/result**, только после ручного подтверждения пользователя.
