# Отчёт 02.1 (исправление безопасности)

Отдельный optional astro_editor: SDL3 окно, bgfx D3D11, ImGui docking,
File/New/Open/Close/Exit, View/панели/Reset layout. Панели Project и Diagnostics.
Создание требует нового каталога, существующий каталог не перезаписывается.
`project.astro` записывается во временный файл, синхронизируется и публикуется
без замены существующего файла. Временный файл удаляется при ошибке; удаление
каталога ограничено пустым каталогом, созданным этой операцией.
Формат: UTF-8, сигнатура ASTRO_PROJECT, версия 1, quoted name. Открытие
проверяет файл до смены активного проекта. Путь вводится вручную;
родительский каталог должен существовать.

## Команды (VS Developer Command Prompt x64, корень проекта)

    cmake -S . -B build/stack-spike -DASTRO_BUILD_EDITOR=ON
    cmake --build build/stack-spike --parallel 4
    ctest --test-dir build/stack-spike --output-on-failure
    build\stack-spike\editor\astro_editor.exe

Editor выключен по умолчанию; использует подготовленные build/spike-deps.
Никаких загрузок и установок. Headless не зависит от GUI.

## Ограничения

Windows x64/MSVC/D3D11. Renderer пока дублирует проверенный прототип;
выделение общего адаптера оставлено дальнейшему развитию.
Layout не сохраняется между запусками. Интерфейс английский; полный
Unicode-шрифт не подключён. Нет native file dialog, recent projects,
JSON, Scene Model и export. Формат проекта содержит только имя.
Ручная проверка мышью, визуальные эталоны и чистая сборка в новом каталоге
не выполнялись. Формат пока не является межплатформенным контрактом.
