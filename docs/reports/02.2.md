# Отчёт 02.2 — Scene Model, Scene View, Hierarchy

Реализована минимальная in-memory модель сцены в `engine/scene`: ID и имя
сцены, сущности с монотонными scene-local ID, именами и необязательной
ссылкой на родителя. Есть создание, reparent, поиск и удаление; запрещены
пустые имена, отсутствующие родители и циклическое parenting. Удаление
сущности с потомками требует явного recursive-флага.

В editor добавлены панели Hierarchy и Scene View в docking layout. Hierarchy
позволяет создать корневую сущность или ребёнка, выбрать сущность и удалить
выбранное поддерево. Scene View рисует прокручиваемую структурную схему
parent-child и позволяет выбирать узлы. Меню File → New scene создаёт новую
пустую сцену в памяти.

Scene View прямо обозначена как structural preview. У сущностей пока нет
Transform, компонентов или игрового рендеринга. Scene/entity ID не сохраняются
после закрытия процесса. Сериализация, Inspector, schema properties,
Command API-интеграция для GUI и Undo/Redo здесь не реализованы.

## Ограничения и пропущенные проверки

Проверена только Windows x64/MSVC/D3D11. Нет отдельного image-diff теста или
ручной проверки мышью; smoke проверяет отрисовку и docking автоматическими
фактами, но не визуальное качество макета. Нет загрузки/сохранения Scene.
ID действуют только в рамках экземпляра модели. Hierarchy использует простой
поиск по вектору сущностей, достаточный для текущего прототипа, но не
производительный для больших сцен.

Command API. Он не начат.
