# Отчёт 02.3 — Inspector и schema properties

В `engine/scene` добавлена схема свойств сущности: обязательное редактируемое
`name` (UTF-8 string, default `Entity`, максимум 240 байт) и read-only `id`
(unsigned integer с ненулевым диапазоном). Проверяются UTF-8, пустые имена,
NUL, длина, тип значения, существование сущности/свойства и read-only статус.

Добавлена команда `entity.set_property` версии 1 через
`registerSceneCommands()`. `validate` проверяет без изменения модели;
`execute` перепроверяет и применяет значение. Inspector показывает ID,
позволяет подготовить имя и применить его отдельной кнопкой. GUI изменения
свойства выполняются через CommandRegistry, а не прямой setter.

## Ограничения

Схема пока описывает только имя и ID, компоненты и Transform отсутствуют.
Команда non-transactional и является Undo barrier; Undo/Redo относятся к
02.4. Сцены не сохраняются. Регрессионный CTest прошёл только на Windows
x64/MSVC/D3D11. Ручной ввод мышью и визуальный image-diff не выполнялись.

При интеграции CommandRegistry с editor потребовалось согласовать MSVC CRT:
корневой CMake задаёт статический runtime согласованно для проекта и
предсобранных SDL3/bgfx библиотек. Новые внешние зависимости не добавлены.

Следующий рекомендуемый подэтап — 02.4 (сохранение/открытие сцен,
диагностика, Undo/Redo и hotkeys). Он не начат.
