# Отчёт подэтапа 02.4 — сохранение сцен и Undo/Redo

## Объём

Выполнен только подэтап 02.4 дорожной карты. Реализованы текстовый UTF-8 формат Astro Scene v1 для текущих Scene/Entity данных, безопасное атомарное сохранение, загрузка с полной валидацией до смены активной сцены, диагностика редактора, команды Ctrl+S/O/Z/Y и транзакционный Inspector Name. При ошибке открытия активная сцена и путь остаются прежними. Несохранённые изменения блокируют смену проекта/сцены.

## Изменённые файлы

- `engine/scene/include/astro/scene/Scene.hpp`, `engine/scene/src/Scene.cpp` — проверка модели и восстановление сцены с ID/иерархией.
- `engine/scene/include/astro/scene/SceneFile.hpp`, `engine/scene/src/SceneFile.cpp`, `engine/scene/CMakeLists.txt` — файловый формат и атомарное сохранение.
- `engine/core/include/astro/core/CommandRegistry.hpp`, `engine/scene/src/SceneCommands.cpp` — очистка истории и Undo/Redo изменения Name.
- `editor/main.cpp` — меню/горячие клавиши, Save/Open, dirty state, диагностика и расширенный headless smoke.
- `tests/unit/core/CoreTests.cpp`, `tests/integration/scene/SceneCommandTests.cpp`, `tests/integration/scene/SceneFileTests.cpp`, `tests/CMakeLists.txt` — проверки истории, команды и сериализации.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/TESTING.md`, `docs/COMMAND_API.md`, `docs/BUILD_GUIDE.md`, `docs/FILE_FORMATS.md` — пользовательские инструкции и технические ограничения.

## Работающие функции

- Сохранение Scene ID, имён, Entity ID и связей parent-child.
- Загрузка проверяет формат/версию/UTF-8, ID, имена, родителей и циклы; некорректное содержимое не подменяет открытую сцену.
- Сохранение во временный файл с заменой целевого файла на Windows через `MoveFileExW`.
- Ctrl+S, Ctrl+O, Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z; диагностика в редакторе.
- Undo/Redo изменения Name; новое обычное изменение очищает redo-ветку по правилам CommandRegistry.

## Ограничения и риски

- Формат v1 не содержит компонентов, Transform, ресурсов, схемных миграций, резервных копий или восстановления после аварии в середине сохранения; это не Save System.
- Undo/Redo покрывает только транзакционное изменение Name. Создание/удаление сущности не входит в историю.
- Save As отсутствует; первая запись новой сцены идёт в `Scenes/scene_<id>.astro-scene` проекта.
- При dirty-сцене переключение блокируется; диалог выбора «сохранить/отбросить» отсутствует.
- Автоматические smoke-тесты не заменяют ручную проверку GUI/визуальных эталонов. Проверена только Windows x64/MSVC конфигурация.
- Файлы проекта не коммитились и не отправлялись в GitHub. Предшествующие незакоммиченные изменения сохранены.
