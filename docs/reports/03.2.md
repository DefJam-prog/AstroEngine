## Реализация

Добавлена отдельная библиотека `astro_assets` без новых внешних зависимостей. `AssetRegistry::open(projectRoot)` загружает или создаёт `.astro/assets.index`, инициализирует project-local `Assets/` и `Library/Assets/`. `importImage(relativePath)` принимает PNG/JPG/JPEG только из `Assets/`, инспектирует dimensions/формат, даёт устойчивый numeric `AssetId` и сохраняет `AssetReference`. SHA-256 кэширует encoded bytes в `Library/Assets/<hash>.v1.png|jpg`; исходный файл не записывается. Повторный import неизменённого source возвращает тот же ID. Изменение source требует явного `reimport(id)`, который сохраняет ID и обновляет metadata/hash. `missingAssets()` возвращает ID отсутствующих или выходящих за границу проекта путей.

Пути проверяются на traversal, canonical source/cache/index directories не должны выходить из проекта, symlink cache entry и symlink index отклоняются. Индекс и cache публикуются через эксклюзивный временный файл и атомарную замену. В `.gitignore` добавлен generated project cache `/Library/`.

## Работает

- PNG/JPG/JPEG metadata import в пределах заданных размеров и лимитов файла.
- SHA-256 проверен известными unit vectors; cache content-addressed и восстанавливается из source.
- Стабильные project-local numeric AssetId сохраняются в UTF-8 `.astro/assets.index`; повторное открытие и CRLF проверены.
- Явный reimport сохраняет AssetId; source без изменений со стороны инструмента.
- По запросу обнаруживаются отсутствующие/out-of-root source paths.
- Проверяются path traversal, повреждённый PNG, неизвестное расширение, JPEG без frame dimensions, повреждённый index, cache corruption и, когда создание symlink разрешено, cache symlink.

## Ограничения и риски

- Это metadata/import registry, не image decoder. PNG проходит структурную/chunk CRC проверку, но IDAT не распаковывается; JPEG scanner читает marker/SOF и требует EOI, но не декодирует entropy stream. Malformed compressed image data может потребовать отдельной полной проверки перед использованием decoder.
- Cache сейчас побайтно совпадает с encoded source; перекодирование, оптимизация, mipmaps и texture upload не реализованы.
- `AssetReference` ещё не подключён к Component/Scene/SpriteRenderer. Asset Browser и UI-диагностика отсутствуют; это отдельная будущая работа.
- Index ограничен 16 MiB/100000 записей/4096 UTF-8 байт на путь, source — 256 MiB, dimensions — максимум 65535 на сторону и 268435456 пикселей суммарно.
- Старые content cache entries не удаляются автоматически. Одновременное изменение одного index несколькими процессами не защищено file lock.
- Проверена только Windows x64/MSVC. POSIX ветвь атомарной публикации не собиралась/не тестировалась.
