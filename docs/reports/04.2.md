## Реализовано

`InputMapping` связывает именованные actions с keyboard key codes, mouse buttons, mouse delta/wheel и gamepad buttons/axes. Поддерживаются альтернативные bindings, scale/sign, deadzone для аналогового control, `value/down/pressed/released`, кадрирование transient inputs и очистка отключённого устройства. Валидация ограничивает имена actions, число bindings, код устройства, коэффициенты и неfinite значения.

Optional `SDLInputAdapter` преобразует SDL3 key scancode, mouse button/motion/wheel, gamepad button/axis и gamepad removal в backend-neutral API. SDL не подключён к headless input library.

## Ограничения и известные проблемы

- UI для назначения кнопок, persistence профилей и runtime UI интеграция не входят в 04.2.
- SDL keyboard codes представлены SDL scancode целыми числами; сохранённый cross-platform profile format не задан.
- Не добавлены macOS/Android/iOS adapters; физические устройства не проверялись.
- Device enumeration, controller ownership/hot-plug presentation, rumble и capture/conflict UX отсутствуют.
- Action names ASCII-only; mapping не потокобезопасен. Текущий SDL adapter включён в сборку вместе с Windows editor dependencies.
