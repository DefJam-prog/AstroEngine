# Отчёт подэтапа 04.3 — runtime Camera Rig

## Объём

Реализован программный pose/follow API для Camera modes. Renderer, projection matrices, Scene camera component, serialization и editor controls в текущей архитектуре отсутствуют; поэтому acceptance ограничен вычисляемой pose и не заявляет видимый camera rendering.

- `engine/runtime/CMakeLists.txt` — target `astro_runtime_camera`.
- `tests/unit/runtime/CameraRigTests.cpp`, `tests/CMakeLists.txt` — camera rig unit test.
- `docs/CAMERA_RIG.md`, `docs/ARCHITECTURE.md`, `docs/EDITOR_UX.md`, `docs/DECISIONS.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/TESTING.md`, README — API/example, decision and limitations.
- `build/04.3-build.log`, `build/04.3-ctest.log` — final local verification logs.

## Что работает

`CameraRig` поддерживает Custom, FirstPerson, ThirdPerson, Isometric, TopDown, Platformer и Strategy. Режимы имеют documented default offset/rotation; настройки можно заменить через `configure`. Custom принимает ручную pose. Follow берёт позицию/rotation напрямую из Transform target entity, применяет world-space offset, exponential follow smoothing, optional AABB bounds и zoom range. Missing target/invalid settings/frame delta выдаёт Result diagnostics; target Scene не изменяется.

## Ограничения

- Target Transform используется в локальных координатах; parent/world transform composition ещё отсутствует.
- Offsets задаются в world axes; ThirdPerson и остальные не делают автоматический look-at; FirstPerson только наследует Euler rotation.
- Нет projection/FOV/view matrix, camera component, persistence, renderer integration, editor UI и визуального golden/reference.
- Физический camera output на экране не проверялся.
