## Реализовано

`PhysicsWorld2D` binds runtime `Body2D` and `BoxCollider2D` values by EntityId to one SceneId. Fixed-step updates integrate dynamic velocity/gravity, detect 2D axis-aligned box overlaps, resolve solid penetration on the smallest axis, and publish ordered `CollisionEvent` Enter/Stay/Exit events through the existing EventBus. Trigger overlaps do not resolve physically. A RuntimeSession caller supplies the runtime Scene copy and fixed delta.

Bindings and body state are not serialized. The integration test confirms a dynamic body falls onto a static floor, stops along the contact normal, emits Enter then Stay, emits Exit when separation occurs, reports trigger contact without correction, rejects invalid/cross-scene inputs, and leaves the authoring Scene unchanged.

## Ограничения

Только axis-aligned boxes, XY plane, static/dynamic body types, discrete pairwise collision detection (O(n²), максимум 2,048 тел), простая positional correction. Нет вращения, масс, трения, упругости, CCD, joints, сериализации, editor UI или runtime renderer. Быстрые тела могут пролетать сквозь тонкие коллайдеры. Сбой EventBus observer возвращает ошибку после применения шага; состояние не откатывается.
