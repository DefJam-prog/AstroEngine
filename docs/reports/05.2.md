## Реализовано

GameUiModel exposes MainMenu, Gameplay, Paused and Settings, available actions, HUD fields and typed boolean/numeric/choice setting values. Start/pause/resume/return-to-menu coordinate with RuntimeSession. The SDL3/ImGui adapter renders the screens, routes mouse/keyboard input through the model API, and provides responsive full-window layout. `astro_game_ui_demo.exe` demonstrates the flow without launching the editor.

## Ограничения

HUD/settings are runtime memory only. The demo applies UI scale and fullscreen; it has no audio engine, persistent settings, localization, controller navigation or game asset/theme pipeline. The SDL3/ImGui adapter is optional and Windows-only in this project configuration. The visual reference covers the main-menu screen only; no manual usability study was performed. Event listeners are synchronous and cannot roll back a screen/setting transition after notification failure.
