# Подэтап 05.3 — звук, анимации и игровая логика головоломки

## Изменения

- Добавлен dependency-light `astro_runtime_puzzle`: seeded match-three доска, adjacent swap validation, run/cascade removal, gravity/refill, score и progression по score threshold.
- Добавлен `AnimationTrack`: scalar keyframes с validation, linear interpolation и clamp на концах.
- Добавлен optional SDL3 `SdlAudioCuePlayer` для queueing коротких synthesized `Select`, `Match`, `LevelUp` tones. Game UI demo запускает этот backend только вне smoke режима, сообщает об отказе audio device и продолжает без звука.
- Добавлены unit tests gameplay/animation и SDL dummy-audio smoke. Обновлены README, ARCHITECTURE, ROADMAP, STATUS, DECISIONS, TESTING и руководство `PUZZLE_AND_ANIMATION.md`.

## Проверка

```powershell
cmake --build build/stack-spike --parallel 4
ctest --test-dir build/stack-spike --output-on-failure

Чистая headless-конфигурация без SDL/ImGui также успешно сконфигурирована, собрана и прошла CTest **19/19**. Логи находятся в `build/05.3-build.log`, `build/05.3-ctest.log`, `build/05.3-headless-configure.log`, `build/05.3-headless-build.log` и `build/05.3-headless-ctest.log`.

## Ограничения

Нет визуальной игровой доски/ввода игрока, уровней из файлов, сохранения прогресса, objectives/special tiles/dead-board reshuffle, Scene property binding для анимаций, audio assets, mixer, spatial audio или проверки на физических динамиках. Поэтому это проверенное ядро правил и адаптер cue-звуков, а не готовая для игрока 2D-головоломка.
