## Commands and results

Run from a Visual Studio 2022 x64 Developer Command Prompt. CMake and dependencies were already present locally; no installs or network downloads occurred.

```powershell
cmake -S . -B build/05.10-runtime-package -G Ninja `
  -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON `
  -DASTRO_BUILD_GAME_UI_DEMO=ON `
  -DASTRO_BUILD_WINDOWS_RUNTIME_PACKAGE=ON `
  -DASTRO_BUILD_STACK_SPIKE=OFF -DASTRO_BUILD_EDITOR=OFF
cmake --build build/05.10-runtime-package --target astro_game_ui_demo --parallel 6
ctest --test-dir build/05.10-runtime-package `
  -R runtime.windows.package.clean_start --output-on-failure --no-tests=error
cmake --build build/05.10-runtime-package --target package --parallel 6
ctest --test-dir build/05.10-runtime-package --output-on-failure --parallel 6
```
