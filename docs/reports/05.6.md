## Изменения

- Added opt-in `ASTRO_BUILD_WINDOWS_RUNTIME_PACKAGE`, gated to Windows x64/MSVC and the existing `ASTRO_BUILD_GAME_UI_DEMO` target.
- Added CPack ZIP install rules for `astro_game_ui_demo.exe`, `README-runtime.txt`, SDL3 license and Dear ImGui license. No editor, test assets, or build tools are included. The dependency licenses are taken from the already prepared local `build/spike-deps`; no download or new dependency was added.
- Added `runtime.windows.package.clean_start`: CPack creates the archive, the test extracts it into a fresh unique build directory, checks its executable/README/license files and launches the extracted exe with `--smoke` from that directory.
- Updated README, architecture, roadmap, status, decisions, testing, and Windows build instructions.

## Ограничения и известные проблемы

- The ZIP is a distributable Game UI prototype, not the completed 2D puzzle game required by Stage 05 acceptance. It has no visible multi-level board and does not connect puzzle progress with save slots/checkpoint systems.
- Runtime package verification is on Windows x64/MSVC only. No other toolchain/platform was tested. Archive has no app signing or installer.
- Including SDL3 and ImGui license texts is not a complete legal review. AstroEngine has no selected project license and all dependency distribution terms still require a broader review before release.
- Audio device behavior, arbitrary-user-machine compatibility, and clean machines without the installed Windows graphics/audio drivers were not tested. The packaged `--smoke` uses SDL's hidden window/software renderer.
