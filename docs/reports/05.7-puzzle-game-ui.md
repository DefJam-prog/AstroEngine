# 05.7 — Puzzle board in runtime Game UI

Date: 2026-11-15  
Scope: one bounded continuation of Stage 05 to connect the existing Puzzle rules to the optional SDL Game UI demo. Unity scripts were not run.

## Changes

- Added an optional host-owned gameplay content callback to `ImGuiGameUiAdapter`; callers that do not set it retain the existing UI behavior.
- The SDL demo owns an 8×8 `PuzzleGame` with fixed seed `9123`, draws colored tile buttons under the Gameplay HUD, and routes neighboring tile selections through `PuzzleGame::swap`.
- Successful moves update the existing score and level HUD. Starting a new game resets the board. Existing RuntimeSession Play/Pause/Resume/return-to-menu transitions remain in use.
- Added the Russian board instruction translation and `runtime.game_ui.puzzle.smoke`.
- The Puzzle runtime target is built when the optional Game UI demo is requested, including configurations with tests disabled. The default headless build remains independent of SDL/ImGui and Puzzle.

## Limitations

- This is a seeded demo board, not an authored campaign or level loader.
- Puzzle progress is not connected to SaveStore/checkpoints and resets on Play.
- No pixel-golden was added for the Puzzle board; appearance is only checked through produced ImGui draw data.
- Physical mouse/gamepad behavior was not manually tested.
- The 05.6 Windows ZIP was not rebuilt or clean-start tested after this change. The source package README now describes the board that the next package build will contain; an already-created archive is unchanged.
- Stage 05 acceptance remains incomplete; this substage does not begin Stage 06 or the Unity compatibility work.
