# Подэтап 06.1 — Visual Logic prototype

## Результат

Добавлены optional C++20 `astro_visual_logic` и панель **View → Visual Logic** в редакторе. Прототип поддерживает константы Number/Boolean/String, арифметику, числовые сравнения, AND/OR/NOT и конкатенацию строк. Типы входов проверяются при соединении, граф ограничен 128 узлами, литералы/результаты строк — 4096 байт. Evaluator детерминирован; debugger умеет Run, Step, Reset и показывает состояние/результат каждого узла.

Встроенный пример вычисляет `(4 + 3) > 6 AND true`. API evaluator не зависит от SDL/bgfx/ImGui; отдельная production-конфигурация собрала его без Editor. UI редактора использует уже существующие зависимости, новые внешние библиотеки не добавлялись.

## Проверки

Среда: Windows 11 x64, Visual Studio 2022 Build Tools, MSVC 19.44, CMake 3.31.6, Ninja 1.12.1.

Из Developer PowerShell x64:

```powershell
cmake --build build/stack-spike --parallel 4
ctest --test-dir build/stack-spike --output-on-failure
cmake --build build/05.3-headless --parallel 4
ctest --test-dir build/05.3-headless --output-on-failure
```

Фактический итог: optional/editor build успешен, CTest **28/28**; headless build успешен, CTest **23/23**. Отдельно конфигурация Release с `BUILD_TESTING=OFF`, `ASTRO_BUILD_EDITOR=OFF`, `ASTRO_BUILD_VISUAL_LOGIC=ON` успешно собрала `astro_visual_logic`.

Тесты покрытия: `visual_logic.unit` (типы, литералы, ограничения, связи, циклы, удаление узлов и предел размера); `visual_logic.execution.integration` (результаты графа, стабильный порядок и пошаговая трасса, ошибки вычисления); `editor.smoke` проверяет панель и исполняемый пример. Ручное взаимодействие с меню UI не автоматизировано.

Логи: `build/06.1-baseline-editor.log`, `build/06.1-baseline-headless.log`, `build/06.1-build.log`, `build/06.1-editor-ctest.log`, `build/06.1-headless-final.log`, `build/06.1-logic-runtime-configure.log`, `build/06.1-logic-runtime-build.log`.

## Ограничения и риски

- Граф существует только в памяти редактора: нет файла, сохранения/загрузки, миграций, undo/redo и тестов persistence.
- UI представляет узлы вертикальным списком, связи выбираются из typed menus; нет визуального canvas и drag-wire.
- Это pure dataflow: нет ветвления/событий управления потоком, Scene mutation, gameplay command nodes или запуска графа в игре.
- Debugger синхронный и однопоточный; нет breakpoints и профайлера.
- Поэтому критерий этапа 06 «собрать новую механику через GUI без C++» пока не выполнен.

Решение и границы описаны в [D036](../DECISIONS.md#d036--keep-visual-logic-061-as-a-pure-typed-dataflow-prototype) и [VISUAL_LOGIC.md](../VISUAL_LOGIC.md). Следующий рекомендуемый подэтап — **06.2 UI Editor**, но он не начат; ожидать ручного подтверждения пользователя.
