# 06.18 — Puzzle level authoring

## Scope and implementation

This substage adds a bounded first authoring path for Puzzle levels; it does not implement the full T01 template/campaign. `PuzzleLevelDefinition` contains a stable safe ID, UTF-8 name, board dimensions, tile palette size, seed, target score and exact initial tile IDs. `PuzzleGame::create(definition)` validates and starts that exact board. The existing seeded `PuzzleGame::create(width, height, seed, ...)` API is unchanged.

`PuzzleLevelFile` reads/writes UTF-8 version 1 under `<project>/Puzzle/Levels/<ID>.astro-puzzle-level`. It bounds document size and board allocation, validates IDs/names/tile ranges, rejects traversal, malformed/trailing input and unsupported versions, and publishes via a sibling temporary plus atomic replacement. Version 1 has no migration path.

The Game View's **Puzzle Level Authoring** panel edits one in-memory draft: ID/name, dimensions (3–16 in the GUI), tile kinds (3–8), seed, target score and individual cells (click cycles the tile ID). The user can create a default draft, load/save by ID and play the current draft. The editor resets the in-memory draft when switching projects.

The active authored level disables the old preview's progress Save/Load controls: those slots do not contain a level ID and cannot safely validate a snapshot against a different authored starting board. Existing manual slots continue to work in the built-in sample mode. No user files or old save slots were deleted or migrated.

## Known limits and next step

Only one draft is edited at a time; there is no level browser, campaign/transition model, delete/duplicate controls, draft Undo/Redo, migration, legal-move validation, or progress slots keyed by level. The next recommended substage is to add explicit per-level save identity and tests before re-enabling save/load for authored levels, or expand the level library workflow if that is the desired priority. Neither was started here.

The worktree had earlier uncommitted user/project changes; they were preserved. No commit or GitHub push was made.
