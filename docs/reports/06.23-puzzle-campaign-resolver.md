# 06.23 — Puzzle campaign runtime transition resolver

## Scope

Added a pure resolver for one campaign completion request, plus integration coverage for score thresholds, DEFAULT, END, and one-edge semantics. No Editor UI, level loading, or progression orchestration was added.

## API and behavior

`resolvePuzzleCampaignTransition(campaign, completedLevelId, finalScore)` is declared in `astro/runtime/PuzzleCampaign.hpp` and implemented by `astro_runtime_puzzle`.

- Validates the campaign before resolving.
- Rejects a completed level ID that is not in the campaign with `NotFound`.
- Evaluates that source level's descending score thresholds in their stored order and returns the first target whose threshold is at most the final score.
- Returns the source's DEFAULT target if no score condition matches.
- Returns a successful empty `std::optional<std::string>` for `DEFAULT END`.
- Resolves exactly one edge. It does not mutate campaign state, load a destination, or recursively follow the destination's rules. The host must make a later completion request to resolve the next edge.

The integration fixture has two thresholds for `intro`: score 900 chooses `bonus`; score 500 chooses `finale`; a lower score falls back to DEFAULT `bonus`. Completing `finale` returns END. Tests also reject an unknown source and make a separate resolver call for the destination to assert that one call never advances multiple edges.

## Limitations

- The Editor cannot author campaigns yet.
- No runtime host currently loads the returned level or orchestrates automatic progression.
- Renaming a level referenced by a campaign is not reference-safe; leave referenced level IDs unchanged until that is implemented.
- The existing worktree had unrelated uncommitted changes before this substage. They were preserved; no commit or push was made.

## Recommended next substage

Add host-side progression orchestration that loads the resolver's selected level and defines what happens at END, with tests proving state/progress handling. Keep campaign Editor authoring as separate work.
