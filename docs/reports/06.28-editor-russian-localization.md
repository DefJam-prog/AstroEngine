# Подэтап 06.28 — язык Windows Editor

## Изменения

- Добавлен внутренний каталог переводов English/Russian для пользовательских строк Windows Editor.
- Добавлено окно **Edit → Settings…** с переключением языка и кнопками Apply/Cancel.
- Предпочтение сохраняется в versioned `editor-settings.cfg` под SDL user preference path. Не меняются проект, сцены и игровые ресурсы.
- Добавлена загрузка системного Segoe UI для кириллицы с Arial fallback и расширенным набором glyph ranges.
- Добавлен unit-тест перевода/настроек и проверка покрытия прямых ImGui строк; Editor smoke открывает Settings в режиме Russian.

## Проверка

- Сборка: `cmake --build build/stack-spike --parallel 4` — успешно; `editor/astro_editor.exe` слинкован.
- Полный тестовый набор: `ctest --test-dir build/stack-spike -C Debug --output-on-failure -j 4` — **41/41 passed**, **6.31 s**.
- Фокусная регрессия: `ctest --test-dir build/stack-spike -C Debug --output-on-failure -R '^editor\.(localization\.unit|smoke)$'` — **2/2 passed**, ранее в этом подэтапе.
- Результат полного CTest: `build/localization-full-ctest.log`; вывод финальной сборки: `build/localization-build.log`.
- `git diff --check` проверяется перед завершением.

## Ограничения

- Это локализация UI Windows Editor, не всей экосистемы программы: SDL Game UI demo, низкоуровневые API/driver diagnostics и часть динамических сообщений могут оставаться на английском.
- Пользовательские имена и содержимое намеренно не переводятся.
- Автоматический smoke подтверждает кодовый путь/рендеринг окна настроек, но не заменяет ручную оценку качества русского текста и визуальное QA на разных DPI.
- Для системного шрифта в Windows ожидается Segoe UI; резерв — Arial. Шрифты не включаются в проект.
