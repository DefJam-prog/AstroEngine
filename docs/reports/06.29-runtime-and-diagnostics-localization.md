# Подэтап 06.29 — SDL Game UI и диагностики

## Изменения

- Добавлен backend-neutral каталог `GameUiLocalization` с English/Russian, отображаемыми названиями и точными переводами встроенных ошибок Game UI.
- На SDL Game UI demo появился пункт **Language** (`en`/`ru`) в существующей модели настроек; переключение применяется сразу. Профиль пользователя не создаётся, выбор сохраняется только в модели процесса.
- Переведены меню, пауза, экран настроек, системные HUD подписи, встроенные настройки и распознанные диагностики.
- В русском UI неизвестная диагностика получает локальную метку ошибки, а исходный текст сохраняется. В Editor известные ошибки переводятся из каталога, а неизвестные диагностические строки получают «Ошибка редактора:».
- Для runtime русский шрифт Segoe UI/Arial подключается отдельно от default font. Английская типографика и существующий visual baseline сохранены.
- Smoke переключает Game UI на русский и обратно; unit-тесты покрывают коды языка, каталоги и диагностический fallback.

## Проверки

- До изменений: Debug build успешен; полный CTest **41/41** за **6.31 s**.
- Первое изменение глобального шрифта нарушило эталон Game UI (`mean MAE=1.089437`, 2.672% канал-отклоняющихся пикселей); английский default font восстановлен, Segoe UI применяется только при русском.
- Сборка после изменений: `cmake --build build/stack-spike --parallel 4` с предварительной инициализацией `vcvars64.bat` — успешна.
- Фокусный тест: `ctest --test-dir build/stack-spike -C Debug --output-on-failure -R '^(runtime\.game_ui\.localization\.unit|runtime\.game_ui\.visual\.smoke|editor\.localization\.unit|editor\.smoke)$'` — **4/4 passed**, **5.41 s** до последней проверки Unicode path handling.
- Итоговый полный CTest после всех изменений: **42/42 passed**, **8.66 s**. Точный лог: `build/localization-runtime-full-ctest.log`.
- `git diff --check` прошёл без ошибок.

## Ограничения

- Выбор языка SDL demo временный; он не записывается в пользовательские настройки.
- Перевод неизвестных системных ошибок не меняет внутреннюю деталь SDL/драйвера; она отображается исходной строкой после русской метки.
- Пользовательские имена и тексты HUD не изменяются. Runtime data localization для игр не реализована этим подэтапом.
- Проверка русской ветки автоматическая; ручная проверка визуального качества на разных системах/DPI не проводилась.
