# Подэтап 06.3 — Timeline and camera preset editor

## Реализовано

- Добавлен `AnimationTimeline`: редактирование ordered scalar keyframes с проверкой, sample, seek, play/pause, reset и остановкой на конечном ключе.
- `View → Timeline` показывает список ключей, редактирует time/value, добавляет/удаляет ключи, scrubbing, воспроизведение и preview-кривую. Для кривой используется тот же `AnimationTrack::sample`, что и runtime-код.
- `AnimationTrack`/`AnimationTimeline` отделены в optional `astro_runtime_animation`. Флаг `ASTRO_BUILD_ANIMATION_RUNTIME=ON` включает его без Editor и SDL/bgfx/ImGui. Для совместимости `ASTRO_BUILD_PUZZLE_RUNTIME=ON` по-прежнему транзитивно линкует этот target.
- `View → Camera Presets` открывает режимы существующего `CameraRig` (First/Third Person, Isometric, Top-Down, Platformer, Strategy), позволяет назначить entity target и редактировать Custom pose; выводит вычисленные position/rotation/zoom.
- Editor smoke выполняет проверку Timeline sampling и вычисление ThirdPerson pose для выбранного target.

Внешние зависимости не добавлены.

## Проверки

Окружение: Windows 11 x64, Visual Studio 2022 Build Tools/MSVC 19.44, CMake 3.31.6, Ninja 1.12.1. Из x64 Developer PowerShell/Command Prompt:

```powershell
cmake --build build/stack-spike --parallel 4
ctest --test-dir build/stack-spike --output-on-failure
cmake --build build/05.3-headless --parallel 4
ctest --test-dir build/05.3-headless --output-on-failure
```

Итоговые сборки прошли. Полный Editor CTest: **31/31**; headless CTest: **26/26**. Первый Editor CTest запускал старый `stack_spike.smoke`, который один раз не получил синтетическое клавиатурное событие (`keys=0`). Изолированный повтор этого smoke прошёл, затем полный Editor CTest прошёл 31/31.

Также выполнена отдельная Release-проверка без Editor и тестов:

```powershell
cmake -S . -B build/06.3-animation-only -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DASTRO_BUILD_ANIMATION_RUNTIME=ON -DASTRO_BUILD_EDITOR=OFF -DASTRO_BUILD_GAME_UI_DEMO=OFF
cmake --build build/06.3-animation-only --target astro_runtime_animation --parallel 4
```

Эта конфигурация успешно собрала только animation target без SDL/bgfx/ImGui. Новые и регрессионные проверки: `runtime.animation.unit`, `camera.rig.unit`, `editor.smoke`, Puzzle unit и остальной CTest. Численные результаты и журналы находятся в `build/06.3-*.log`.

## Ограничения

- Timeline поддерживает один scalar track и линейную интерполяцию. Нет нескольких tracks, easing, событий, graph/state machine, Scene-property binding, Undo, serialization или runtime export.
- Ключи редактируются таблицей и playhead slider; drag-key editing на самой кривой отсутствует. Данные теряются при закрытии Editor.
- Camera panel вычисляет pose, но не показывает camera image. Нет Scene camera component, projection/view/FOV и сериализации.
- Сравнение UI/camera pixel-golden и ручная проверка изображения не проводились, так как камера не связана с renderer.
- Существующий `stack_spike.smoke` показал единичную нестабильность события клавиатуры на первом полном прогоне; повторный одиночный и последующий полный прогон прошли.
