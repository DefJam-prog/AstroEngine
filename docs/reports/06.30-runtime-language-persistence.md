# Подэтап 06.30 — сохранение языка runtime

## Цель и продуктовая фиксация

В [PRODUCT_REQUIREMENTS.md](../PRODUCT_REQUIREMENTS.md) зафиксировано: AstroEngine — универсальный модульный движок/редактор 2D/3D-игр, AI-assisted authoring — ключевое отличие; Unity/Godot/Unreal/CryEngine — ориентир по широте, но не заявление о текущем паритете. GUI и AI должны использовать один typed Command API, AI adapter не требуется для запуска игр, Puzzle — проверочный вертикальный срез, а не жанровая граница. Решение D067 закрепляет направление; README, ARCHITECTURE, ROADMAP, STATUS и AI_INTEGRATION синхронизированы.

## Изменения

- Добавлен `readGameUiLanguagePreference` / `writeGameUiLanguagePreference` с форматом `ASTRO_GAME_UI_SETTINGS 1` и строгим значением `LANGUAGE en|ru`.
- Отсутствующий файл означает English; неподдерживаемая версия/локаль дают диагностику, не меняя проект и игровой профиль.
- SDL Game UI demo читает и сохраняет язык под `SDL_GetPrefPath("AstroEngine", "AstroEngine")/game-ui-settings.cfg`. При выборе языка запись идёт во временный соседний файл и публикуется безопасной заменой.
- Ошибки чтения/записи выводятся в Game UI; диагностические шаблоны настроек получают русский текст, а системная часть (например, причина отказа ОС) сохраняется.
- Визуальный smoke создаёт уникальный temp каталог, проходит событие `SettingChanged` для Russian и English, читает обе записи назад и удаляет только свой каталог. Он не затрагивает пользовательский SDL settings path.
- Мастер-ТЗ и продуктовая документация синхронизированы; Puzzle зафиксирован как пример/вертикальный срез, не как предел продукта.

## Ограничения

- Настройка относится к standalone SDL Game UI demo; для полноценной игры из Build/Export единое пользовательское preference API ещё не спроектировано.
- Runtime язык хранит только `en|ru`; проектные/игровые значения пользовательского контента не локализуются автоматически.
- SDL/драйвер/ОС могут передавать техническую деталь на исходном языке; её не переписываем и показываем после локализованного сообщения.
- Полноценный AI Editor API, Codex adapter и универсальный 3D runtime остаются целями, а не готовыми функциями.
