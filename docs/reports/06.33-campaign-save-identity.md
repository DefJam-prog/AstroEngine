# 06.33 — Identity каталогов сохранения Puzzle-кампаний

Дата: 2026-11-15.

## Решение

Каталог Editor campaign slots имеет вид:

```text
<SDL user-data root>/<userDataSubdirectory in .astro/puzzle-save.settings>/PuzzleCampaigns/<campaign-id>
```

`resolvePuzzleCampaignSaveDirectory` — чистый path resolver: проверяет настройки относительного каталога и безопасный ASCII campaign ID; не создаёт директории и не меняет файлы.

- Новому ID кампании соответствует отдельная директория. Старые слоты остаются там и не копируются, не удаляются и не переписываются. Старая кампания продолжит их видеть при возврате к её ID и совместимым файлам.
- Перенос проекта с `.astro/puzzle-save.settings` сохраняет настроенный относительный namespace и доступ к тем же слотам.
- Копирование sidecar также копирует этот namespace: две копии проекта используют одни и те же слоты, пока одна копия не настроена на другой `userDataSubdirectory`.
- Если sidecar ещё нет, default каталог строится из hash текущего canonical project path; перемещение до инициализации settings приводит к другому default namespace.
- Автоматического обнаружения/миграции сохранений нет. Настройка другого каталога меняет активный namespace, но не переносит старые файлы.

Реальный перенос/копирование игровых слотов намеренно не выполнялся: он требует отдельного подтверждения пользователя и отдельного подэтапа с preview, конфликтами, сохранением источника и откатом.

## Изменённые файлы

- `editor/ProjectFile.hpp`, `editor/ProjectFile.cpp` — объявлен и реализован проверяемый resolver каталога.
- `editor/main.cpp` — Game View использует resolver; smoke проверяет отдельные campaign ID, безопасную валидацию и сохранение namespace после копирования sidecar в Unicode-путь.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/SAVE_SYSTEM.md`, `docs/PUZZLE_CAMPAIGNS.md`, `docs/TESTING.md` — описаны правила namespace и ограничения.

## Ограничения

- Проверена только Windows x64/MSVC Release конфигурация.
- Копии sidecar разделяют namespace по решению D095; automatic clone isolation не реализовано.
- При смене campaign ID старые слоты не преобразуются под новый ID.
- Миграция, перемещение или копирование настоящих slot files не выполнялись и требуют отдельного подтверждения.
