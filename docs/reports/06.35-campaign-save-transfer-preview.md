# Подэтап 06.35 — Read-only preview переноса campaign saves

**Результат: implemented, API only.** Реальный перенос файлов и UI не входят в этот подэтап.

## Что добавлено

- `SaveStore::inspectExistingSlot` проверяет только уже существующий каталог и возвращает read-only inspection, не создавая writable store. `inspectDetailed` возвращает metadata, custom fields и размер успешно разобранного primary-файла или `.bak`; прежний `inspect` сохраняет свою сигнатуру и поведение результата.
- `previewPuzzleCampaignSaveTransfer` проверяет слоты 0–9 без создания каталогов. Для каждого слота сообщает Empty, Valid, RecoveredFromBackup, Invalid или CampaignMismatch; ID кампании, активный level ID, END, объём ожидаемых файлов и target-конфликты primary/backup.
- Неожиданные файлы и временные артефакты исходного каталога перечисляются отдельно, не включаются в слоты молча.
- Проверки пути запрещают `..`, symlink и Windows reparse points в компонентах каталогов и ожидаемых slot-файлах. Небезопасный campaign ID отклоняется.
- Integration fixture проверяет Unicode source/target, absent target без создания, recovery из backup, повреждённый и неподдерживаемый slot, ID mismatch, collisions и неизменность исходных primary/backup bytes. Создание directory symlink проверяется при наличии соответствующих прав хоста.
- На этом Windows-хосте создание directory symlink недоступно; соответствующая ветка пропущена и не считается проверенной.

## Ограничения

- API не подключён к Editor UI и не выполняет копирование, переименование, repair или удаление.
- Проверка формата/CRC и identity не доказывает, что Puzzle snapshot совместим с текущими authored levels и правилами. Перед будущей загрузкой/переносом нужна стандартная полная валидация campaign session.
- Preview является снимком наблюдений без блокировки файлов; будущая запись обязана повторно проверить source и target непосредственно перед публикацией.
- Конфликт обозначается для любого существующего target primary/backup. Preview не выбирает политику overwrite и не разрешает продолжение автоматически.
