# 06.36 — Editor read-only preview campaign save transfer

Date: 2026-11-15  
Scope: connect the existing 06.35 read-only runtime API to the Editor settings UI. No save transfer or migration.

## Result

`Puzzle Save Settings` now has a **Preview save transfer** action. It compares the currently applied campaign-save namespace to the destination directory draft and displays the 06.35 preview: slot status, campaign identity, size, recovery/backup state, target conflicts and unexpected source artifacts. The displayed preview is cleared when the destination path changes.

The normal Windows source root is obtained by reading `%APPDATA%` and appending the established application directory. This path intentionally avoids `SDL_GetPrefPath`, which may create the directory. If the environment variable is unavailable, the UI reports a diagnostic. Editor smoke invokes the same preview path using a temporary fixture and asserts that the destination directory remains absent and the source slot file is unchanged.

This UI does not save the edited setting, create a directory, copy/repair/delete files, resolve conflicts, migrate data, or validate the Puzzle snapshot against the current authored levels. The standard campaign load remains the compatibility check. A manual live project with populated saves was not opened for visual review; the Editor window was inspected at startup without a project, and the automated Editor smoke exercised the feature UI path.

## Known limitations

- Preview is a point-in-time inspection; files can change after display. No write action exists here, so a future transfer must re-run and compare the preview immediately before any operation.
- Current preview validates format and identity but not compatibility of saved Puzzle state against authored campaign rules.
- Live visual inspection with a populated project/save directory was not performed. Automated Editor smoke checked the rendered feature path and side-effect assertions.
- This remains Windows Editor UI; no macOS/Linux UI verification was performed.
