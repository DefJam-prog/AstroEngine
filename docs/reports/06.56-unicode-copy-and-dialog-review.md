# 06.56 — Unicode copy path and confirmation-dialog review

## Scope and plan

This follow-up validates the 06.55 bounded copy-aside path at a Unicode parent directory and visually inspects its Editor confirmation dialog. It does not change the runtime/save format or add product behavior. The Editor inspection mode uses only the built-in isolated smoke project and is cancelled without producing a copy.

## Changes

- Added a `runtime.puzzle.campaign.save.integration` fixture under `Проверка копии Ω`. It confirms the generated copy remains adjacent and that the copy, conflicting occupant, malformed journal and candidate slot retain exact expected bytes.
- Added test-only Editor mode `--smoke-inspect-copy-dialog`. It opens the real confirmation modal with the existing smoke fixture, waits for manual Cancel, verifies the destination was not created and validates that source/journal/slot remain unchanged. It then exits through the normal smoke cleanup path.
- Updated README, architecture, roadmap, status, decisions, testing and Save System documentation.

## Limitations

Unicode path behavior was tested on the current Windows filesystem and WSL Ubuntu filesystem only. The WSL run is automated, not visual; no claim is made for macOS, other POSIX filesystems or mobile targets. The visual pass checked layout and legibility at the current window size, not high-DPI/scaled layouts or other languages. One Ninja recovery warning occurred during a build; despite exit code 0 and passing tests, its cause was not investigated in this substage.
