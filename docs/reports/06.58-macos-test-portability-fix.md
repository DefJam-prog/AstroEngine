## Change

Both tests construct unique temporary directory names using the count from `std::filesystem::file_time_type`. The underlying `duration::rep` may differ between platform standard libraries, so each count is now explicitly converted to `long long` before calling `std::to_string`. This selects an exact overload while keeping the test's temporary-path behavior. No production source or public API changed.
