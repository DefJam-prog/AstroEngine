# Подэтап 06.6 — Типизированные поля SaveStore для T01 Puzzle

## Объём

Добавлен минимальный runtime-мост между игровыми данными и уже существующим SaveStore. Профиль явно перечисляет дополнительные ключи и тип каждого значения (`string`, `double`, `bool`); приложение передаёт соответствующую map при save/load. Автоматическое сохранение всей Puzzle-доски и GUI авторинг в этот срез не входят.

## Изменения

- `SaveProfile::addCustomField/removeCustomField` валидируют ASCII ID, типовой пример, конечность числа и лимит строки.
- Новые перегрузки SaveStore проверяют точное соответствие ключей и типов профилю и публикуют прочитанные значения только после проверки документа и Scene-кандидата.
- `ASTRO_SAVE 2` сериализует custom records, включает их в CRC32 profile fingerprint и property count. Custom key ограничен 128 байтами, custom string — 64 KiB, сумма записей — 100000.
- Профили без custom fields по-прежнему записываются как `ASTRO_SAVE 1`; Scene-only API сохраняет прежнюю сигнатуру, а parser принимает v1/v2.
- Интеграционный тест проверяет round-trip числа, bool и UTF-8 строки, отклонение пропущенных/лишних ключей и неверных типов, selection mismatch, non-finite number, версию файла и отсутствие частичного изменения при ошибке.

## Ограничения

- Custom values — типизированная map вызывающего кода, не registry произвольных свойств и не автоматическая сериализация `PuzzleSnapshot`.
- Нет миграции содержимого между schema/game versions; несовместимость отклоняется.
- Нет GUI выбора custom keys, профилей-предустановок или checkpoint authoring для этих значений.
- CRC32 предназначен для обнаружения случайного повреждения, не для защиты от читов.

Следующий рекомендуемый подэтап после ручного подтверждения: привязать PuzzleSnapshot к этим явно выбранным полям с определённым версионируемым payload и round-trip тестом; до этого не подключать его к GUI.
