# 07.1c — Scene model asset references

## Scope

This substage connects the optional static glTF importer to the existing Scene and asset identity model. It does not add a 3D renderer view, import materials or transforms, or extend prefab persistence.

## Implemented

- Added `MeshRenderer` component schema v1 with a stable model AssetId, mesh and primitive indices, and visibility.
- Added typed `entity.set_mesh_renderer` command with validation, transactional execution, audit, and undo/redo that preserves ComponentId.
- Advanced Scene text serialization to v6. Readers continue to accept v1–v5; older scenes load without MeshRenderer, and an explicit save writes v6.
- Advanced `.astro/assets.index` to v3. The registry accepts v1/v2 and stores model records with an Assets-relative `.gltf`/`.glb` path, top-level source size/SHA-256, and importer content digest.
- Added model registration, lookup, resolution, and missing-source diagnostics. Re-registering the same source retains its AssetId.
- Added `GltfImporter::importAndRegister`, which registers only after the bounded importer succeeds.
- Prefab capture rejects scenes with MeshRenderer. This prevents a prefab round trip from silently dropping the newly added component.

## Boundaries and known limitations

- MeshRenderer is serialized and command-addressable, but is not drawn in Editor Scene View, Game View, or runtime.
- Prefab files do not store MeshRenderer; capture fails explicitly until prefab schema/override semantics are implemented.
- AssetRegistry validates the top-level model file's size and hash. External buffer changes are reflected when the importer is rerun; individual external buffer dependencies are not stored as separate registry records.
- Scene checks a nonzero model ID and structurally valid indices; resolving the model and checking mesh/primitive bounds belongs to the importer/consumer path.
- Geometry remains static triangle POSITION data with optional indices. Normals, UVs, materials, image dependencies, node transforms, animation and physics are unsupported.
- No macOS/mobile build, fuzzing, sanitizer run, hostile concurrent filesystem-race test, or visual 3D comparison was performed.
