# 07.1d — Scene MeshRenderer resolution

## Goal

Resolve one persisted Scene `MeshRendererComponent` against the project AssetRegistry and bounded glTF importer, returning the selected geometry only when the reference and selected indices are valid and the imported content still matches the registered record.

## Implementation

- Added `astro/render3d/SceneMeshResolver.hpp` and `SceneMeshResolver.cpp` to the optional `astro_gltf` target.
- `resolveMeshRenderer(registry, component)` validates the component schema and nonzero registered Model AssetId; asks AssetRegistry to validate the top-level model source; imports/loads current model input; compares the importer digest against the registered digest; checks mesh and primitive indices; and returns owned backend-neutral `MeshData`, mesh name, asset identity, selectors and visibility.
- A source or external-buffer change fails closed with a diagnostic. Explicit `GltfImporter::importAndRegister` updates the digest while preserving the AssetId, after which the resolver succeeds again.
- The selected primitive is moved from the import result, avoiding an extra vertex/index buffer copy.
- The optional target links `astro_scene`; no glTF or Scene dependency was added to `astro_core` or the default headless build.
- Expanded the glTF integration test for success, visibility, invalid/zero AssetId, unsupported component schema, mesh/primitive bounds, stale top-level source, stale external buffer, reimport, and stable ID behavior.

## Limitations

- This is a data resolver, not a renderer. No draw calls or Editor Scene/Game View integration are included.
- Geometry is imported again or loaded from the verified derived cache on each resolution; there is no retained decoded-geometry cache.
- Per-buffer dependency records, materials, textures, UVs, normals, node transforms and animation remain unsupported.
- macOS/mobile builds, sanitizers, fuzzing and visual comparison were not run. Filesystem protection retains the importer limitations already documented for 07.1b and does not claim resistance to hostile concurrent path replacement.
