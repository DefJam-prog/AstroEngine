# 07.1f — Editor Scene View Mesh preview

## Scope

Connected the existing optional glTF importer/resolver to the Editor's **Scene View**. The Game View and gameplay runtime remain unchanged. The feature is compiled only when CMake has the optional `astro_gltf` target; importer-off Editor remains 2D-only.

## Implementation

- Added a separate BGFX 3D pass ordered after the existing Scene 2D pass and before the Game View/UI composition.
- Scene View's sampleable color target now has a depth attachment. Both attachments are released on resize/teardown, and both BGFX views are detached before replacing the framebuffer.
- Visible Scene `MeshRenderer` entries resolve through `AssetRegistry` and `resolveMeshRenderer`. Static BGFX vertex/index buffers are cached by entity and model/mesh/primitive selection and released when the component becomes invisible/disappears or the target is destroyed.
- Composes Transform matrices from root through the entity, including position, Euler rotation and scale. Missing transforms/parents, invalid values and parent cycles skip the affected mesh and show a Scene View diagnostic.
- Added `Reload 3D meshes` to explicitly invalidate GPU resources and re-resolve imported data.
- Extended `editor.smoke` with the existing glTF triangle fixture in an isolated temporary project. The fixture is attached to a child entity; the test requires at least one draw submission and verifies world X after parent scale/local translation. No user project/resource is changed.
- Added Russian localization for the new Scene View labels.

## Verification

- Importer-on Windows x64/MSVC Release configure/build succeeded using the existing local dependency and .NET SDK caches.
- Focused `editor.smoke` and two BGFX graphics smokes: **3/3 passed**.
- Full CTest suite: **49/49 passed in 9.90 s**.
- Direct Editor smoke: D3D11, 140 frames, 139 Scene View render frames, 139 3D mesh submissions, transformed child origin `(2.75,0,0)`.
- Importer-off Editor build succeeded; localization + Editor smoke: **2/2 passed in 3.41 s**.

## Limits

This is a Windows D3D11 prototype with a fixed camera at `(0,0,5)`, position/color-only static triangle geometry, no back-face culling and a 65,536-vertex/196,608-index limit. It has no normals, UVs, materials, textures, lighting, automatic camera framing, 3D gizmos, picking, Game View/runtime integration or cross-platform validation. The Editor cache has no file watcher: modified assets must be reimported/registered and the user must press Reload. Smoke validates submission and transforms, not golden pixels or performance.
