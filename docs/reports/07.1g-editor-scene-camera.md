# 07.1g — Управление камерой и кадрирование Scene View

**Результат:** завершённый Windows x64 прототип в границах Scene View.

## Реализовано

- Правая кнопка мыши + drag — orbit; средняя кнопка + drag — pan; колесо — zoom.
- Ввод принимается только над отображаемой областью Scene View.
- Кнопка **Frame All** кадрирует видимые `MeshRenderer` по общим world-space bounds.
- Bounds строятся преобразованием восьми углов локального AABB после композиции parent/local transforms. Для одного меша набор bounds принимается целиком или отклоняется; невалидные/слишком большие координаты не оставляют частичный результат.
- Камера отделена в тестируемый editor-модуль без ImGui, SDL и BGFX. Числовой ввод ограничен, некорректное значение не должно отравлять состояние камеры.
- Русские подписи для Frame All и подсказка управления.

Game View и runtime не изменены. Нет 3D-гизмо, picking, материалов, UV/normals, света, pixel-golden сравнения или проверки других платформ. Геометрия остаётся в лимите 65,536 вершин и 196,608 индексов из предыдущего подэтапа.

## Проверка

Из VS 2022 x64 Developer PowerShell:

```powershell
cmake --build build/07.1f-editor3d-release --parallel 8
ctest --test-dir build/07.1f-editor3d-release -R "^(editor\.scene_view_camera3d\.unit|editor\.localization\.unit|editor\.smoke|runtime\.render3d\.(bgfx|scene\.bgfx)\.smoke)$" --output-on-failure
ctest --test-dir build/07.1f-editor3d-release --output-on-failure
```

Подэтап прошёл Windows x64/MSVC Release build; focused набор — **5/5 за 5.02 с**, весь набор — **50/50 за 9.82 с**. Прямой Editor smoke сообщил 139 3D submissions, world origin child `(2.75,0,0)`, `frameAll=1`, `cameraDistance=5.36656`; результат сохранён в `build/07.1g-editor-smoke-20261117.log`. `editor.smoke` проверяет BGFX mesh submission, иерархическое положение дочернего меша и применение Frame All. Unit-тест покрывает начальную позу, orbit, pan, zoom, ограничения, корректные и некорректные bounds/aspect ratio, большие числа и сохранение состояния после отказа. Логи: `build/07.1g-final-build-20261117.log` и `build/07.1g-final-ctest-20261117.log`.

MSVC сообщил три предупреждения C4189 для неиспользуемых локальных переменных в существующем C# metadata smoke-коде. Pixel golden, importer-off пересборка и macOS/iOS/Android не проверялись.
