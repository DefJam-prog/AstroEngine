# 07.1h — Scene View visual smoke and mesh diagnostics

**Результат:** smoke покрывает несколько видимых мешей, частичное восстановление при неверной ссылке и фактическое наличие геометрии в Scene View на Windows x64/D3D11.

## Изменения

- Smoke-сцена содержит два `MeshRenderer` с существующим тестовым glTF и третий с корректным ненулевым, но незарегистрированным AssetId.
- Счётчики Scene View показывают число отправленных 3D мешей и диагностики в последнем кадре. Ошибка одного asset reference не блокирует два валидных draw calls.
- Editor запрашивает текущий BGFX swapchain screenshot и анализирует crop Scene View по нормализованным координатам viewport. Smoke требует не менее 32 почти белых пикселей тестовой геометрии. В измеренном прогоне обнаружено 11 900.
- Frame All проверяется на объединённых bounds: мировые центры экземпляров — `x=2.75` и `x=5.25`, общий центр камеры — `x=4`.

Данные генерируются в изолированном smoke-проекте; проект удаляет только собственные тестовые пути. Пользовательские игровые ресурсы и репозиторные fixtures не изменяются.

## Проверка

Из VS 2022 x64 Developer PowerShell, используя локально настроенную конфигурацию и dependency caches:

```powershell
cmake --build build/07.1f-editor3d-release --target astro_editor --parallel 8
& build/07.1f-editor3d-release/editor/astro_editor.exe --smoke
ctest --test-dir build/07.1f-editor3d-release `
  -R "^(editor\.scene_view_camera3d\.unit|editor\.localization\.unit|editor\.smoke|runtime\.render3d\.(bgfx|scene\.bgfx)\.smoke)$" --output-on-failure
ctest --test-dir build/07.1f-editor3d-release --output-on-failure
```

До изменений полный Release CTest прошёл **50/50 за 14.44 с**. После — focused CTest **5/5 за 4.85 с**, полный CTest **50/50 за 9.47 с**. Прямой Editor smoke: 278 суммарных 3D submissions за 139 отрисованных Scene View кадров, два submissions в последнем кадре, один unresolved AssetId diagnostic, `frameAll=1`, `cameraFocusX=4`, `sceneViewWhitePixels=11900`. Логи: `build/07.1h-prechange-build-20261117.log`, `build/07.1h-prechange-ctest-20261117.log`, `build/07.1h-final-build-20261117.log`, `build/07.1h-editor-smoke-20261117.log`, `build/07.1h-focused-ctest-20261117.log`, `build/07.1h-final-ctest-20261117.log`.

## Ограничения

BGFX screenshot API в этой интеграции снимает swapchain окна, а не внутренний Scene framebuffer. Проверка поэтому вырезает viewport и использует широкий порог наличия белой геометрии; порог не проверяет конкретные формы/цвета/расположение и не является golden. Значение 11 900 зависит от viewport, драйвера и растеризации. Mac/iOS/Android и другие Windows GPU/backend не проверялись. Сборка выдаёт три MSVC C4189 предупреждения в существующих C# metadata smoke locals.
