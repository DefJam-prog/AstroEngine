# 07.2ac — local alpha ramp around MASK cutoff

## Scope

Exercise a smooth 8-bit texture alpha transition concentrated around MASK cutoff 0.5 through the existing mip-filtered Windows Editor Scene View. Generated PNGs remain inside disposable smoke projects. No renderer policy, material schema, runtime API, dependency or user asset is changed.

## Implementation

Added two CTest cases using a 64×64 RGBA image whose alpha increases smoothly from 112 to 143 across U. The material uses MASK/cutoff 0.5, Repeat and `LinearMipmapLinear`, at UV scales 2 and 4. Each checks one mipmapped MASK submission, a broad visible mask-pixel range and visible blend-through from the translucent object beneath it.

## Limits

The broad pixel-count check is not an image golden and does not correlate pixels to particular source alpha values. It does not inspect selected hardware mip LOD or establish behavior on other GPU drivers, graphics backends or platforms. Only the current Windows D3D11 editor path was exercised.
