# 07.2ad — spatial checks for the MASK alpha ramp

## Scope

Strengthen the 07.2ac mipmapped alpha-ramp smoke so it checks approximate spatial ordering, not just global mask/blend totals. Keep the change in disposable Editor smoke code. No runtime API, renderer policy, material schema, dependency or user asset changes.

## Implementation

The two cutoff-transition smokes zoom the Scene View camera by one deterministic wheel input of +5 after Frame All, only in this test mode, so the rendered mask covers enough screen pixels for coarse regional checks. The captured Scene View crop is split into 64 vertical screen-space bins. Existing color classifiers count magenta MASK and cyan blend-through pixels in each bin.

A bin is mask-rich at >=120 magenta pixels and at least twice its cyan count. A bin is blend-rich at >=100 cyan pixels and at least twice its magenta count. Neutral and mixed bins are allowed. The test requires the first decisive region to be blend-rich, at least two rich bins of each type, and at least three changes in dominant class, matching the left-to-right U ramp, Repeat wrapping and minification.

## Limits

The checks are coarse screen-space counts, not an image golden or per-texel oracle. They depend on this fixture's triangle UV orientation, display/window scale, current D3D11 color values and rasterization. They do not read selected hardware LOD or establish other GPU driver, backend or platform behavior. The test zoom affects only these two smoke modes.
