# 07.2ag — SDL Windows DPI metrics

## Finding

The 07.2af 125% run initially looked as if SDL had missed Windows DPI because the log only printed `SDL_GetWindowPixelDensity() == 1.0`. A live Win32 probe of the smoke HWND resolved the ambiguity: its awareness context was **PerMonitorV2**, and `GetDpiForWindow()` returned **120 DPI** while the Windows display scale was 125%. The Editor therefore was running as a DPI-aware process on the scaled primary display.

Added `SDL_GetWindowDisplayScale()` to the Editor smoke output. All six 07.2ae ramp profiles, run while both active displays were temporarily set to 125%, reported:

```text
displayScale=1.25
pixelDensity=1
windowPixels == windowLogical
```

These are distinct SDL metrics. `SDL_GetWindowDisplayScale()` reflects the Windows content/UI scale. `SDL_GetWindowPixelDensity()` is the ratio between window pixel size and SDL window size; a value of 1 does not mean the display scale was ignored. The Editor passes `SDL_GetWindowSizeInPixels()` to BGFX for swapchain dimensions. This diagnostic did not change window sizing or renderer behavior.

The finding corrects the initial interpretation in [07.2af assessment](07.2af-active-windows-dpi-assessment.md): there was no evidence that process DPI awareness was missing. The smoke verified a real Windows 125% desktop scale and corresponding SDL display scale, but did not exercise a separate backbuffer pixel-density ratio above 1.

## Validation

Environment: Windows 11 x64, MSVC 14.44, SDL 3.5.0, BGFX D3D11, Release tree `build/07.2d-release-clean`.

Build:

```powershell
cmake --build build/07.2d-release-clean --config Release --parallel 8
```

The build succeeded. Existing warnings C4456 and C4189 remain.

Focused ramp command at Windows 125%:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release -V -R '^editor\.scene_view_mask_mips\.cutoff_transition\.'
```

Result: **6/6 passed in 17.80 s**.

Full CTest at 125% initially passed **83/84 in 95.24 s**. `runtime.render3d.base_color_texture.bgfx.smoke` transiently failed to publish its disposable cache/index (Windows error 5); an isolated rerun passed **1/1 in 0.87 s**. After restoring both displays to 100%, the full CTest passed **84/84 in 94.67 s**.

Display scaling was restored to 100%. `Screen.AllScreens` returned the original primary and secondary dimensions, 1080×1920 and 2560×1440. The secondary logical origin differs by one pixel due to Windows layout rounding.

Logs: `build/07.2ag-dpi-probe-build.log`, `build/07.2ag-dpi-probe-ctest.log`, `build/07.2ag-full-ctest-125dpi.log`, `build/07.2ag-failed-rerun-125dpi.log`, and `build/07.2ag-final-ctest-100dpi.log`.
