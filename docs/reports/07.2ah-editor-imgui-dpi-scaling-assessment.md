# 07.2ah — оценка DPI-масштабирования Editor UI

## Цель и границы

Проверить, применяет ли текущий Windows Editor фактический SDL display scale к шрифтам и геометрии Dear ImGui после диагностики 07.2ag. Это assessment исходников и baseline проверки: код UI, CMake, системные настройки дисплеев и пользовательские файлы не менялись.

## Наблюдения

- `editor/main.cpp` загружает Segoe UI или Arial фиксированного размера 16 px. `io.ConfigDpiScaleFonts` и `io.ConfigDpiScaleViewports` не включены; multi-viewport flag не запрашивается.
- Используемый SDL3 ImGui backend заполняет `ImGuiPlatformIO::Monitors[].DpiScale` через `SDL_GetDisplayContentScale`. В 07.2ag реальный smoke HWND подтвердил Windows PerMonitorV2/DPI 120, а SDL сообщил `displayScale=1.25`.
- В vendored Dear ImGui 1.93.1 WIP `ConfigDpiScaleFonts` выключен по умолчанию. Документация API уточняет, что этот переключатель масштабирует шрифты, но пока не style spacing/padding.
- Следовательно, SDL scale распознаётся, но текущий Editor не включает ImGui font scale policy; DPI-aware pixel dimensions BGFX swapchain не доказывают, что текст и layout интерфейса увеличиваются.
- `io.DisplayFramebufferScale` — отдельная величина для сопоставления draw-data и framebuffer. Использовать её вместо monitor DPI scale нельзя.

## Проверка

Окружение: Windows 11 x64, Visual Studio 2022 Build Tools 17.14.45, CMake 4.4.4, CTest 4.4.4, Release каталог `build/07.2d-release-clean`. Дисплеи оставались на исходных 100%.

```powershell
cmd.exe /d /s /c 'call "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat" -arch=x64 && cmake --build build\07.2d-release-clean --config Release --parallel 8'
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure
```

Build завершился успешно как no-op (`ninja: no work to do`). Полный CTest: **84/84 passed**, **90,72 s**. Никакого визуального smoke с окнами при 125% в этом подэтапе не выполнялось.

## Вывод и следующий рекомендуемый подэтап

Масштаб SDL/Windows доступен, однако ImGui не использует его для текущего Editor UI. Следующий рекомендуемый подэтап 07.2ai — ввести явную DPI политику Editor: базовая копия style, контролируемый scale font и размеров style без накопления, обработка перехода между мониторами, а затем визуальные проверки 100%/125% и регрессия стандартного масштаба. Не менять системный scale автоматизированным тестом; 125% проверять изолированным тестовым способом или вручную по отдельному разрешению.
