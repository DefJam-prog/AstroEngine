# 07.2ap — диагностики активной камеры в Game View

## Результат

3D camera/render diagnostics теперь отображаются прямо поверх изображения Game View в компактной полупрозрачной карточке. Карточка использует clipped draw region: длинное сообщение не растягивает окно и не вытесняет изображение. Общий русский каталог покрывает сообщение об отсутствии активной Camera3D, причину нулевого/out-of-range Transform и подпись диагностики. Неизвестная техническая причина получает переводимый префикс с сохранённым исходным текстом.

Два новых smoke запускают отдельный временный Editor project: без active Camera3D и с active камерой, имеющей нулевой scale. Они проверяют фактическую ветку построения UI diagnostic, соответствующее русское сообщение и то, что 3D pass не заявляет camera-driven frame/mesh submissions. Обычный Editor smoke сохраняет проверку успешной активной камеры и Game View 3D draw. При ошибке камеры прежний 2D Game View остаётся действующим.

## Изменённые файлы

- `editor/main.cpp` — diagnostic overlay в Game View; test-only smoke варианты для выключенной камеры и нулевого camera scale.
- `editor/Localization.cpp` — русский перевод подписи и camera/Transform diagnostics.
- `editor/CMakeLists.txt` — `editor.game_view_camera_no_active.smoke` и `editor.game_view_camera_invalid.smoke` (только при наличии optional `astro_gltf`).
- `tests/unit/editor/LocalizationTests.cpp` — проверки новых русских переводов.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/TESTING.md`, `docs/3D_RENDERING.md` — контракт, статус, решение D176 и test coverage.
- `docs/reports/07.2ap-game-view-diagnostics.md` — этот отчёт.

## Замечания и ограничения

- Во время разработки smoke с отдельным корневым Entity камеры вызвал Dear ImGui assertion `Missing TreePop()`. Test-only камера была помещена в существующую иерархию сцены, не добавляя MeshRenderer и не меняя пользовательские проекты; оба сценария после этого прошли отдельно и в полном прогоне.
- MSVC оставляет предупреждения `C4530` и отключённые в этой конфигурации C# metadata-validator `C4189`; ошибок сборки нет.
- Overlay проверен на Windows D3D11, DPI и иных GPU/backend configurations отдельно не проверялись. Очень длинное diagnostic может обрезаться clip-карточкой. Тест проверяет построение/локализованный текст UI-пути, а не точное pixel golden текста.
- Формат Scene и публичный API не менялись. Smoke изменяет только свой временный fixture project.
- Git worktree оставлен незакоммиченным: в нём до этого подэтапа уже были многочисленные пользовательские изменения; они сохранены.
