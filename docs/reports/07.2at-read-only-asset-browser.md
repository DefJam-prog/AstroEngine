# 07.2at — read-only Asset Browser

## Реализация

Окно Project теперь содержит начальный Asset Browser, который объединяет только записи текущего `AssetRegistry`: image, model, material и script. Строки отсортированы по стабильному AssetId и показывают тип, ID и registry-relative source path. Выбор ресурса ведёт в существующую карточку Project.

Доступны фильтр типа (`All`, Images, Models, Materials, Scripts) и поиск по UTF-8 подстроке source path или десятичного AssetId. Поиск точный и чувствителен к регистру. ImGui list clipper создаёт widgets только для видимой области.

Каталог кэшируется на время работы проекта; он перестраивается при смене project root, изменении количества записей в Registry maps или по кнопке Refresh. Внешние изменения `.astro/assets.index` не попадают в открытую in-memory registry и требуют повторного открытия проекта. Каталог не сканирует файловую систему, не показывает незарегистрированные файлы, не импортирует, не открывает и не изменяет ресурсы.

## Изменённые файлы

- `editor/AssetBrowserModel.hpp`, `editor/AssetBrowserModel.cpp` — объединение записей, типы каталога и фильтрация.
- `editor/main.cpp`, `editor/CMakeLists.txt` — Project UI, кэш, selection, smoke mode и регистрация тестов.
- `editor/Localization.cpp`, `tests/unit/editor/LocalizationTests.cpp` — локализация интерфейсных меток.
- `tests/unit/editor/AssetBrowserModelTests.cpp` — проверка всех четырёх registry types, порядка, фильтров и UTF-8 пути.
- Обзор записан в корневом `README.md` и документах architecture, roadmap, status, decisions, UX, asset pipeline и testing.

## Известные ограничения

- 100k-entry стресс-тест и frame-time profiling каталога не проводились. UI rows ограничены clipper, но поиск сканирует весь кэшированный список при изменении запроса.
- Поиск чувствителен к регистру, включая кириллические символы.
- Неизвестные AssetIds и файлы, не зарегистрированные в AssetRegistry, не отображаются.
- Не реализованы дерево папок, drag-and-drop, preview, open action, группировки и сортировка, изменяемая пользователем.
- Изменения registry index другими процессами не синхронизируются с открытым project snapshot.
- Smoke проверяет action через harness; реальные mouse/keyboard interactions не автоматизированы.
- Поддержан только Windows Editor D3D11; остальные BGFX backends и standalone runtime не проверялись.
- В сборке остаются MSVC предупреждения C4530/C4189; они не блокируют Release.
