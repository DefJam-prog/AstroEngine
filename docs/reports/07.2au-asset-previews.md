# 07.2au — предпросмотр зарегистрированных ресурсов

## Изменения

Окно Project показывает миниатюру выбранного зарегистрированного изображения (192×144 ImGui area), используя уже загруженный BGFX texture cache или загружая только `AssetRegistry::cachedPath(id)` через имеющийся Windows WIC loader. Для выбранной зарегистрированной glTF модели Project запускает текущий bounded importer по registry-owned пути и отображает число meshes, primitives, vertices и triangle indices. Сообщение importer показывается, если файл больше нельзя прочитать/импортировать. Результат модели кешируется до смены выбранного ресурса.

Добавлен `editor.asset_model_preview.smoke`: отдельный временный проект выбирает fixture model через Asset Browser и подтверждает ожидаемые значения 1 mesh, 1 primitive, 3 vertices и 3 indices. Существующий Asset Browser smoke дополнен проверкой image thumbnail. Локализованы новые подписи. Сцена, исходные игровые Assets и source model не меняются; glTF importer может создать/переиспользовать производный кэш под `Library`.

## Ограничения

- Model preview — это сводка геометрии, не вращаемый визуальный 3D viewport.
- Не реализованы preview material/script, preview незарегистрированных файлов, drag-and-drop и открытие ресурса.
- Проверена только Windows x64, MSVC 2022 и BGFX D3D11. Smoke использует UI harness, без ручной проверки мышью.
- Сводка модели не обновится до повторного выбора, если внешний процесс изменит файл при открытом Project; для синхронизации сначала нужна повторная регистрация/обновление AssetRegistry.

## Рекомендуемый следующий подэтап

Отдельно спроектировать и реализовать model preview viewport с независимыми BGFX view/framebuffer lifecycle, камерой и framing. Не расширять текущую геометрическую сводку до обещания визуальной модели.
