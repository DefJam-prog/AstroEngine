# 07.2av — изолированный 3D preview модели в Project

## Что добавлено

При выборе зарегистрированной glTF-модели в Project редактор создаёт временную Scene с одним `MeshRenderer` на каждый imported primitive и отправляет её в отдельный `SceneViewTarget`. Target использует свои BGFX views 5/7, цветовой/depth framebuffer, mesh/material texture cache и `SceneViewCamera3D`; Scene View использует 1/3, Game View 2/4, ImGui — view 0. Таким образом, preview не переключает рабочую сцену или Game View camera.

Камера кадрирует объединённые bounds модели при выборе. Правая кнопка мыши вращает, средняя панорамирует, колесо масштабирует. При выборе другого AssetId/root Project очищает GPU mesh/material cache. Панель автоматически прокручивается к выбранному preview, чтобы viewport был виден сразу. На экране остаётся geometry summary и importer/render diagnostics.

Preview ограничивает модель до 128 primitives и 64 MiB combined vertex/index buffers, сверх существующих ограничений на каждую геометрию и material texture cache. Temporary Scene находится только в памяти. Исходная Scene и Assets не меняются; glTF importer может создать производный cache в `Library`.

## Ограничения

- Проверена Windows x64, MSVC 2022, BGFX D3D11. Нет проверки других backends/OS.
- Smoke проверяет финальные пиксели screenshot crop, но физические mouse orbit/pan/zoom не автоматизированы.
- Stress tests на 128 primitives и 64 MiB не запускались; не поддерживаются skeletal animation, arbitrary mesh formats, lighting authoring и preview материалов из Asset Browser отдельно от source model materials.
- Если внешний процесс меняет модель при открытом Project и та же запись остаётся выбранной, viewport не выполняет автоматический reimport/watch. AssetRegistry нужно обновить повторной регистрацией, затем сменить выбор и вернуться к модели.
- C4530 и C4189 compiler warnings остаются; они не блокируют данную Release-сборку.
