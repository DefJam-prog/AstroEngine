# 07.2ay — compact Project model preview after resize

## Scope

Исправить clipping выбранного model viewport в Project panel после изменения размера окна и добавить smoke, который проверяет именно полную видимость viewport в компактном окне 864×608. Scene, model source, material, camera controls и пользовательские игровые ресурсы в рамках этого подэтапа не менялись.

## Изменение

Project panel запоминает свой размер. Когда ширина или высота меняется больше чем на один логический пиксель, повторно разрешается `SetScrollHereY(0.5f)` для активного model preview. Так viewport вновь прокручивается в видимую область после восстановления/уменьшения окна.

Существующий `editor.asset_model_preview.smoke` теперь проходит через 1280×800 и заканчивается при 864×608. Каждый кадр проверяется прямоугольник ImGui image относительно текущего clip rect Project window; итоговый smoke требует, чтобы весь viewport помещался в clip rect. Проверка pixel crop продолжает требовать минимум 32 foreground pixels модели.

## Ограничения и рекомендуемое продолжение

Проверена геометрическая видимость, не точное совпадение с visual golden. Физический orbit правой кнопкой и pan средней кнопкой всё ещё не прошли ручную проверку через текущую Computer Use автоматизацию; программные camera-control методы остаются отдельным покрытием 07.2aw. Проверка выполнена на Windows Release, BGFX D3D11; другие платформы и graphics backends не проверены. Следующим рекомендуемым пунктом будет ручная валидация реального orbit/pan, когда доступен ввод right/middle mouse.
