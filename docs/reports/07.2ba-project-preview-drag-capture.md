# 07.2ba — drag capture in Project model preview

## Scope

Make right-drag orbit and middle-drag pan in the selected Project model preview continue while the pointer temporarily leaves the image rectangle. A drag starts only inside the visible preview; a press that begins outside must not begin controlling the model. Release and selection changes must clear the capture.

This change is limited to Project model preview. The main Scene View interaction was not changed.

## Implementation

The Project preview tracks independent right and middle capture states. `ImGui::IsMouseClicked` inside the preview image activates a state. While active and `ImGuiIO::MouseDown` remains true, orbit/pan consumes `MouseDelta` even when the pointer is outside the image. A released button clears its state. Changing the selected asset or project clears both states. Wheel zoom remains limited to hovering the preview.

The existing SDL event smoke now presses near the preview edge, moves outside while held, and checks yaw/focus changes only while the image is not hovered. It then presses each button outside the image and moves back inside while held; the camera must remain unchanged. The smoke also requires both capture states to be cleared after release.
