# 07.2bb — drag capture в Scene View

## Результат

В Rendered Scene View правый drag вращает временную 3D-камеру, а средний drag панорамирует её. Жест начинается только при нажатии внутри viewport, продолжает работать за его границами, пока кнопка удерживается, и завершается при отпускании. Правый/средний press снаружи viewport не начинают жест. Колесо по-прежнему масштабирует камеру только при наведении на viewport. Изменяется только редакторская камера; данные сцены не редактируются.

Ранее Scene View обрабатывал orbit/pan только пока курсор оставался над viewport. Теперь его поведение согласовано с Project model preview.

## Реализация

`editor/main.cpp` хранит независимый capture для правой и средней кнопок. Capture включается при ImGui click, если курсор наведён на Rendered viewport; camera callback выполняется, пока соответствующий `MouseDown` остаётся true, без дополнительной проверки hover. Release сбрасывает capture. Wheel zoom остаётся в hover-ограниченном блоке.

Существующий smoke `editor.asset_model_preview.smoke` расширен отдельной последовательностью событий для Scene View. SDL motion/down/up проходят штатный event pump и `ImGui_ImplSDL3_ProcessEvent`. Проверки подтверждают, что press внутри действительно пришли при hover, yaw/focus меняются после движения за границу, обе кнопки отпускаются, и отдельные right/middle press снаружи реально получены, но не изменили камеру. Сравнения выполняются после кадра обработки GUI-события, чтобы не проверять состояние раньше Scene View callback.

## Проверки

Сборка: `build/07.2d-release-clean`, x64 Release, MSVC 14.44, SDL 3.5.0, Dear ImGui 1.93.1 WIP, BGFX D3D11. Сборка завершилась успешно. MSVC вывел C4530 (`/EHsc`) и три C4189 для C# metadata diagnostics locals; эти предупреждения не относятся к изменённому input handler.

Команды выполнены из Developer Command Prompt for VS 2022 (среда MSVC x64):

```bat
cmake --build build/07.2d-release-clean --config Release -j 8
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --verbose --output-log build/07.2bb-scene-view-drag-smoke.log -R "^editor.asset_model_preview.smoke$"
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure --output-log build/07.2bb-focused-ctest.log -R "^(editor\.asset_model_preview\.smoke|editor\.smoke|editor\.localization\.unit|editor\.workspace_layout_policy\.unit|editor\.scene_camera_pose\.unit)$"
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure --output-log build/07.2bb-full-ctest.log
```

- Целевой smoke: **1/1 за 3,13 с**; лог содержит `sceneViewRightDrag=1`, `sceneViewMiddleDrag=1`, `sceneViewOutsidePressIgnored=1`, `sceneViewDragReleased=1`.
- Фокусная регрессия: **5/5 за 6,24 с**.
- Полный CTest: **96/96 за 129,49 с**.

## Ограничения

Проверка использует synthetic SDL events в штатном цикле редактора; она не является OS-level `SendInput` и не подтверждает физическую мышь. Проверены Windows x64, BGFX D3D11 и компактное окно 864×608 при UI scale 1,25. Другие ОС, GPU backends и фактический ввод пользователя не проверялись. Визуальный golden для этого изменения не добавлялся: критерии относятся к обработке жестов и изменению состояния камеры.
