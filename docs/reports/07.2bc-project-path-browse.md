# 07.2bc — обзор пути проекта

## Изменения

- Кнопка «Обзор…» размещена рядом с полем пути в «Открыть проект» и «Новый проект».
- Открытие проекта вызывает системный SDL3 file dialog с фильтром `*.astro`; создание проекта — folder dialog для выбора существующего родительского каталога.
- Целевой каталог для создания вычисляется как `parentDirectory / projectName`; имя проверяется на абсолютный путь и разделители. Существующий дочерний каталог не заменяется.
- SDL callback передаёт результат асинхронно, а поле обновляется в главном UI цикле. Отмена не меняет путь. Путь, не помещающийся в поле, отклоняется с локализованным сообщением.
- Русский перевод кнопки и диагностики добавлен в localization unit test.

## Проверка

Конфигурация: Windows x64, MSVC 2022, CMake/Ninja Release, SDL3 3.5.0, dialog subsystem включён.

```powershell
cmake --build build/07.2bc-project-browser --config Release --target astro_editor astro_editor_localization_tests astro_editor_project_path_tests -j 8
ctest --test-dir build/07.2bc-project-browser -C Release --parallel 1 --output-on-failure -R "^(editor\.localization\.unit|editor\.project_path\.unit|editor\.smoke)$"
```

Сборка завершилась успешно. CTest: **3/3 passed** (`editor.localization.unit`, `editor.project_path.unit`, `editor.smoke`; 3,38 с). Unit проверил UTF-8 имя проекта и отказ от пути с `.`/`..` и разделителями. `editor.smoke` также создал временный проект, используя ту же функцию соединения parent/name. Вручную открывались оба системных диалога; file dialog отменён, folder dialog был отменён без выбора каталога. Через UI проект не создавался и пользовательские каталоги не менялись.

## Ограничения

- Полный CTest для этой правки не запускался.
- До изменения `editor.asset_model_preview.smoke` уже падал в этой рабочей сессии при открытом другом окне Editor; данный тест к кнопке не относится и здесь не повторялся.
- Ручное открытие диалогов проверено только на Windows. Автоматической проверки native dialogs, DPI вариантов и macOS/Linux пока нет.
- Поле пути остаётся фиксированного размера; слишком длинный путь не подставляется и сопровождается сообщением.
