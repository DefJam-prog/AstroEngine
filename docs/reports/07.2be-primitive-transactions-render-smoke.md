# 07.2be — транзакционные примитивы и Scene View smoke

## Содержание

Создание Cube, Plane, Sphere и Cylinder через Hierarchy теперь идёт через typed команду `entity.create_primitive`. Удаление выбранной сущности вместе с потомками идёт через `entity.delete_subtree`. Это закрывает разрыв между операциями GUI и общим Command API и делает эти две операции частью Undo/Redo.

## Поведение и тесты

- Dry-run создания и удаления проверяется на копии и не меняет рабочую сцену.
- Undo создания удаляет entity; Redo восстанавливает её с прежними EntityId и PrimitiveRenderer ComponentId.
- Удаление охватывает поддерево. Undo восстанавливает прежние ID, порядок сущностей и parent-ссылку; Redo повторяет удаление.
- Editor smoke изолированно отправляет четыре вида примитивов через `SceneViewTarget`; ожидается `primitiveRenderSmoke=1 submissions=4 diagnostics=0`.
- Обычная smoke-сцена после теста примитивов восстанавливается, поэтому smoke-метрики редактора сохраняют прежний смысл.

Удаление сохраняет полный снимок Scene и prefab-instance metadata, а не минимальный diff удалённого поддерева. Это упрощает корректный rollback на текущем этапе, но память Undo растёт пропорционально размеру документа.

## Фактическая проверка

Windows 11 x64, MSVC 14.44, Release, BGFX Direct3D 11. Сборка выполнялась из окружения Developer Command Prompt, которое подготавливается скриптом `VsDevCmd.bat -arch=x64`:

```powershell
cmake --build build/07.2d-release-clean --config Release --target astro_editor astro_scene_tests astro_scene_command_tests astro_scene_file_tests --parallel 8
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure -R "^(scene\.unit|scene\.command\.integration|scene\.file\.integration|editor\.smoke)$"
ctest --test-dir build/07.2d-release-clean -C Release -V -R '^editor\.smoke$'
```

Сборка завершилась успешно. Целевой набор CTest: **4/4 passed** за 6,12 с. Повторный verbose editor smoke: **1/1 passed** за 2,89 с; фактическая строка `primitiveRenderSmoke=1 submissions=4 diagnostics=0`. Полный Release CTest: **96 passed, 1 skipped из 97** за 126,89 с; единственный пропуск — `editor.window_mixed_dpi.sdl.smoke`, который штатно завершился как skipped без подходящих дисплеев. Регрессии не обнаружены. MSVC вывел предупреждения C4530 об `/EHsc` и ранее существовавшие локальные C4189/C4456; ошибок компиляции не было.

Проверка доказывает регистрацию четырёх mesh submissions без renderer diagnostics, но не pixel golden или визуальную различимость каждой геометрии. Другие ОС и BGFX backends не тестировались.
