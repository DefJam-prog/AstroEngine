# 07.2bf — редактирование PrimitiveRenderer в Inspector

## Изменение

В Inspector для выбранной сущности с `PrimitiveRenderer` добавлена панель с выбором формы (Cube, Plane, Sphere, Cylinder) и флагом Visible. Изменение одного из полей применяет актуальную пару значений одной командой `entity.set_primitive_renderer` v1. Это сохраняет типизированный путь и записывает Undo/Redo; существующий Transform остаётся способом менять позицию, вращение и размер.

Русский интерфейс локализует заголовок, подпись выбора формы и сообщение об успешном применении. Отдельная новая Scene-схема и зависимости не добавлены.

## Покрытие

- Command integration меняет Cube/visible на Sphere/hidden, проверяет Undo к исходной паре и Redo к новой, включая неизменность ComponentId.
- Localization unit проверяет русские строки Inspector.
- Editor smoke рисует те же Inspector-контролы на отдельной невидимой тестовой сущности и проверяет, что показаны форма Cylinder и выключенная видимость. Основная сущность smoke с MeshRenderer остаётся выбранной для существующих camera/material проверок.
- Тест не автоматизирует мышиное нажатие по Combo/Checkbox; применение и история проверяются через ту же команду integration-тестом.

## Результаты Windows Release

Windows 11 x64, MSVC 14.44, BGFX D3D11. Сборка целевых Editor/Scene/Localization целей прошла. Focused CTest завершился **5/5 passed** за 3,51 с. Полный CTest завершился **96 passed, 1 skipped из 97 за 132,46 с**; единственный skip — `editor.window_mixed_dpi.sdl.smoke`, не найдено подходящей пары дисплеев с разным масштабом. Сбоев нет.

Команды:

```powershell
cmake --build build/07.2d-release-clean --config Release --target astro_editor astro_scene_tests astro_scene_command_tests astro_scene_file_tests astro_editor_localization_tests --parallel 8
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure -R "^(scene\.unit|scene\.command\.integration|scene\.file\.integration|editor\.localization\.unit|editor\.smoke)$"
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure
```

Полная проверка не является визуальным golden. На сборке остались предупреждения MSVC C4530 (`/EHsc`) и три неиспользуемые C# metadata smoke-переменные C4189, существовавшие в соседнем Editor коде.
