# 07.2bi — проверка материала примитива в Scene и Game View

## Что проверяется

Editor smoke различает `PrimitiveRenderer` с project material override от обычных `MeshRenderer` объектов и учитывает его material draw submission отдельно для Scene View и Game View. Game View обязан использовать активную Camera3D. Для изображения материал изменён на жёлтый — красный порог предыдущего smoke мог совпасть с красным 2D маркером на полном снимке окна. Новый порог требует не менее 128 жёлтых пикселей в Scene View.

Рендер-контракт и публичный API не менялись: оба viewport уже использовали общий BGFX material path. Подэтап закрепляет различимый регрессионный критерий для каждого viewport.

## Результат

- Scene View: 1 textured material submission для `PrimitiveRenderer`; найдено **402 жёлтых пикселя**.
- Game View: 1 textured material submission для `PrimitiveRenderer`; кадр построен активной Camera3D.
- В снимок включён полный Editor кадр: [PNG](07.2bi-primitive-material-game-view.png).
- Временный smoke project создаётся под build tree и очищается самим тестом; пользовательские игровые ресурсы не меняются.

## Проверки

Среда: Windows 11 x64, MSVC 2022 14.44, Release, BGFX Direct3D 11.

```powershell
& $env:ComSpec /s /c '"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat" -arch=x64 && cmake --build build/07.2d-release-clean --config Release --target astro_editor --parallel 8'
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure -R "^editor\.primitive_material\.smoke$"
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure
```

Focused `editor.primitive_material.smoke`: **1/1 passed**. Полный CTest: **97 passed, 1 skipped из 98 за 122,36 с**. `editor.window_mixed_dpi.sdl.smoke` штатно skipped: не обнаружена подходящая пара дисплеев с разным scale.

## Ограничения

Проверен только Windows x64 BGFX D3D11 путь. Порог в 128 пикселей — smoke, не pixel golden для всех драйверов. Game View подтверждается submission счётчиком для конкретного компонента и активной камеры; отдельного сравнения видимых Game View пикселей нет. Освещение, тени, Play/runtime 3D rendering и экспортный runtime этим шагом не добавлялись.
