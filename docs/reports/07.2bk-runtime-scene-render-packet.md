# 07.2bk — backend-neutral Scene render packet

## Цель

Подготовить Scene к дальнейшему подключению Runtime 3D renderer без переноса
частного кода Editor и без привязки core к BGFX, SDL или конкретному importer.

## Реализация

- Добавлена библиотека `astro_scene_render3d`.
- `buildSceneRenderPacket` обходит Scene, разрешает активную `Camera3D`,
  вычисляет world transforms родителей и собирает видимые `MeshRenderer` и
  `PrimitiveRenderer`.
- Встроенная геометрия создаётся через `MeshData` и совместно используется
  render items одного вида primitive в пределах packet.
- Геометрия `MeshRenderer` передаётся через внедряемый resolver. Это сохраняет
  возможность использовать glTF/importer, не делая его обязательной зависимостью.
- Project material override разрешается через `AssetRegistry` и при наличии
  перекрывает source material. Плохие или отсутствующие данные дают диагностику
  конкретного объекта; объект не попадает в список render items.
- Editor camera pose helper использует общую математику иерархических
  преобразований.
- Добавлены unit и integration тесты на иерархию, камеру, примитивы,
  material override, round-trip Scene file, ошибки resolver и диагностики.

## Границы результата

Packet — CPU snapshot Scene, не готовый renderer. Здесь нет GPU загрузки,
ресурсного cache, render loop, draw submission или интеграции с Play/Runtime.
Если активной камеры нет или её pose некорректен, сборка packet возвращает
ошибку. Ошибки отдельных renderable объектов записываются в diagnostics.

## Проверка

Release-конфигурация Windows x64, MSVC:

```powershell
& $env:ComSpec /s /c '"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat" -arch=x64 && cmake --build build/07.2d-release-clean --config Release --parallel 8'
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure -R "^(runtime\.render3d\.scene_packet\.unit|runtime\.scene\.render3d\.integration|editor\.scene_camera_pose\.unit|editor\.primitive_material\.smoke)$"
ctest --test-dir build/07.2d-release-clean -C Release --parallel 1 --output-on-failure
```

- Полная Release-сборка прошла до последней рефакторизации Editor helper;
  после неё повторно собраны все затронутые цели: `astro_scene_render3d`, оба
  packet test target, `astro_editor_scene_camera_pose_tests`, `astro_editor` и
  BGFX smoke.
- Focused CTest после рефакторизации: **4/4 прошли за 4,39 с**.
- Полный CTest после изменений: **99 passed, 1 skipped из 100 за 130,54 с**.
- Skipped: `editor.window_mixed_dpi.sdl.smoke`; в доступном окружении нет пары
  мониторов с подходящими разными scale factors.
- Сборка сообщает существующие предупреждения MSVC C4530 и C4244 в
  `GltfImporterTests.cpp`; новых ошибок сборки нет.
