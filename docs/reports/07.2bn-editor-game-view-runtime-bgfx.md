# 07.2bn — Runtime BGFX adapter in Editor Play Game View

## Scope

Connected the optional `astro_runtime_bgfx_scene3d` consumer to the Editor's existing Game View. The Editor retains SDL/BGFX/window/framebuffer ownership. When a Play runtime Scene produces a clean packet and the adapter accepts every item/material, the adapter submits the 3D pass to Game View's BGFX view/framebuffer. If packet construction or adapter validation fails (including unsupported texture/alpha cases), the pre-existing Editor 3D renderer handles the full scene pass. Non-Play rendering and builds without the optional adapter keep the existing path.

## Limits

This adapter route is optional and validated only on Windows x64/MSVC/D3D11. It supports vertex colors and opaque `baseColorFactor`; texture maps, alpha blend/mask, full PBR, other render backends and exported runtime hosting are outside this step. Scenes rejected by the packet builder/adapter use the existing Editor renderer. The screenshot is diagnostic, not an exact pixel golden. Three unrelated C# metadata smoke locals still produce MSVC C4189 unused-variable warnings in this build configuration.
