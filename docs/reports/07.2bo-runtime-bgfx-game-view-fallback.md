# 07.2bo — Runtime BGFX Game View fallback for textured materials

## Scope

Added a dedicated Editor Play smoke for the unsupported textured-material path. The test uses the existing Editor smoke Scene, whose glTF fixture and registered project material exercise texture handling. It verifies that BGFX adapter reports no submissions and that the established Editor renderer submits textured meshes. The positive opaque adapter route from 07.2bn remains a separate test. No scene or material API changed.

## Changed files

- `editor/main.cpp` — fallback smoke mode and assertions for adapter/Editor textured submission counters.
- `editor/CMakeLists.txt` — registers the new smoke only when the optional Runtime BGFX target is available.
- `tests/smoke/editor_runtime_bgfx_game_view_fallback.cmake` — executes the Editor smoke and validates its reported route counters.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/3D_RENDERING.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/TESTING.md` — document scope, contract, evidence, and remaining limits.

## Verification

Windows x64, MSVC 2022, Release, existing local SDL3/BGFX dependencies. MSVC's environment must be initialized for C++ standard library headers. Build command used:

```powershell
$vsDevCmd = 'C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat'
& cmd.exe /d /s /c "call `"$vsDevCmd`" -arch=x64 -host_arch=x64 >nul && cmake --build build/07.2d-release-clean --config Release --parallel 8"
```

The Editor target compiled and linked successfully; the subsequent full build reported `ninja: no work to do`.

Focused regression command:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure -R "editor\.runtime_bgfx_game_view(_fallback)?\.smoke|editor\.primitive_material\.smoke|runtime\.render3d\.scene_packet\.bgfx\.smoke|editor\.game_view_registered_asset_diagnostic\.smoke"
```

Result: **5/5 passed in 12.78 s**, including both adapter success and textured Editor fallback. Full Release CTest:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure
```

Result: **102 passed, 1 skipped out of 103 in 130.22 s**, no failures. `editor.window_mixed_dpi.sdl.smoke` skipped because the environment does not provide a suitable pair of monitors.

## Limits

This validates fallback selection and real textured mesh submissions in Editor Game View on Windows x64/D3D11. The adapter still does not render texture maps, alpha blend/mask, or full PBR itself. The fallback assertion uses submission counters, not a pixel-exact visual golden. Other platforms/backends were not tested. No commit or GitHub push was made; the pre-existing working-tree changes were preserved.
