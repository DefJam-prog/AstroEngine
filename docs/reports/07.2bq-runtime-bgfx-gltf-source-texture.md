# 07.2bq — внешняя base-color texture glTF в Runtime BGFX Game View

## Результат

Backend-neutral render packet теперь сохраняет для source glTF base-color изображения local path, SHA-256, UV channel, sampler и UV transform. Поля передаются только для source material без Scene project override; override продолжает заменять весь импортированный material.

Editor host canonicalizes `Assets` и путь изображения перед WIC decode, разрешая чтение только regular file внутри активного проекта. BGFX texture cache использует UTF-8 source path, import SHA-256 и base-color factor. Поддержан тот же ограниченный subset, что и для project texture в 07.2bp: opaque, UV0, identity transform, non-mip nearest/linear minification, nearest/linear magnification, repeat/mirror/clamp. Неподдерживаемые/недоступные ресурсы дают отказ всего adapter pass и сохраняют прежний Editor renderer.

Временный Editor smoke-проект содержит два видимых меша: зарегистрированный project material и source glTF material с внешним PNG без override. Play smoke подтверждает 2 submissions, 2 texture submissions/cache entries, не менее 64 красных пикселей проектной текстуры и не менее 64 голубых пикселей именно source glTF текстуры в Game View. Integration test проверяет передачу source path, hash и sampler metadata в SceneRenderPacket; project override при этом проверяется как имеющий приоритет.

## Ограничения

Проверено только на Windows x64 / MSVC / BGFX D3D11. Runtime BGFX остаётся opt-in Editor adapter, не автономным runtime renderer. Не поддерживаются embedded/data URI images, UV1, UV transforms, mip filters, alpha modes и прочие PBR карты; для них целиком остаётся Editor renderer. Изменения source image требуют обновлённого importer hash/model registration. Визуальный smoke использует тестовый проект и thresholds, не платформенно-независимый golden.
