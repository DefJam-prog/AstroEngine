# 07.2bu — MASK base-color в Runtime BGFX Game View

## Реализация

Runtime BGFX теперь допускает OPAQUE и MASK материалы в ограниченном base-color subset. Для MASK adapter передаёт `alphaMode=1` и настроенный material cutoff в существующий alpha shader uniform; fragments ниже cutoff отбрасываются. Для MASK остаётся включена запись глубины, blending не включается. Shader color-only path также получает uniform, поэтому MASK может использовать alpha из vertex/base-color factor.

Для текстурированных MASK mip levels генерируются в `BaseColorAlphaMipMode::Mask`, где сохраняется достижимая coverage относительно cutoff. Texture cache key различает alpha mode и cutoff, чтобы два разных MASK-материала не разделили несовместимую mip chain. BLEND и неподдержанные material bindings продолжают отклонять весь Runtime BGFX pass с сохранением Editor renderer fallback.

Новый smoke использует source glTF MASK material (cutoff 0.5) и тестовую 64×64 checker PNG с чередованием прозрачных/непрозрачных блоков 2×2. Игровой Play-просмотр подтвердил adapter=1, 2 mesh submissions, 2 textured submissions, 2 texture cache entries, 1 mip texture entry и fallback=0. Game View crop: **4050 project-red pixels**, **83 visible cyan source pixels**. OPAQUE checker в соседних smokes дал 512 pixels для modes 9985/9987; MASK-картинка поэтому сохраняет видимые фрагменты и вырезает прозрачные texels. Порог smoke — 64–400 pixels.

## Ограничения

- Проверен Windows x64 / MSVC Release / BGFX D3D11.
- Поддержаны только OPAQUE/MASK в существующем ограниченном base-color subset: UV0, identity UV transform и существующие sampler modes.
- BLEND, metallic-roughness/normal/occlusion/emissive maps, неподдержанные UV mappings и прочие backend остаются на Editor fallback.
- Pixel count thresholds не являются переносимыми визуальными goldens.
- Свет, PBR BRDF, тени и самостоятельный Runtime host не входят в этот подэтап.
