# 07.2bw — DirectionalLight3D data contract

## Scope

Added the Scene data contract for an optional directional light and handed enabled records to the backend-neutral 3D render packet. This is data plumbing only: the BGFX renderer and Editor Inspector were not changed, and the scene image receives no lighting contribution.

## Changes

- Added `DirectionalLight3DComponent`: stable component ID, schema v1, enabled state, linear RGB in `[0,1]`, and a finite unitless intensity multiplier in `[0,64]`.
- Added `light3d.add_directional`, `light3d.set_directional`, and `light3d.remove_directional` typed transactional commands. Undo/Redo restores exact component IDs and values.
- Scene format now writes v12 with an `astro.DirectionalLight3D` component record. It still reads v1–v11; reading does not rewrite files, while explicit save upgrades the file. No light is inferred for legacy scenes.
- `SceneRenderPacket` carries enabled lights in stable entity-ID order. Direction is normalized local `-Z`, resolved through entity and parent rotations while ignoring translation and scale.
- Direction resolution walks only the light's parent chain; it does not copy the whole Scene for each light.
