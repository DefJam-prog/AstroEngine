# 07.2c — Bounded glTF material metadata import

## Scope

Extended the optional `astro_gltf` importer with source material metadata and references. This is not Scene material assignment or rendering.

## Implementation

- Added backend-neutral import result tables for source images, textures and materials. A material holds supported core metallic-roughness values/alpha settings plus texture-role bindings that point to glTF texture indices and `texCoord` values.
- Preserved each primitive's optional source material index parallel to its geometry primitive.
- Imported base color RGBA, metallic, roughness, emissive RGB, alpha mode/cutoff, double-sided, normal scale, occlusion strength and five core texture roles.
- Preserved local external image references as `Assets/`-relative paths, source size and SHA-256. Bytes are bounded to 64 MiB per image and 128 MiB total, read only, and included in the import freshness digest.
- Preserved embedded array/buffer-view source kinds, MIME metadata, and byte size/hash where bytes are available. Images are not decoded or registered as image AssetIds.
- Kept missing local references and remote/unsupported references visible through diagnostics; remote resources are never fetched. Unsafe traversal and link/reparse paths are rejected.
- Added diagnostics for unsupported source material fields, alternative texture image extensions, texture transforms and used extensions the importer does not interpret.
- Reconstructed material tables/primitive references from source on cache hits; the mesh cache remains geometry-only. The import content-hash namespace was advanced so external image bytes participate in freshness.
- Used fastgltf and its already-pinned simdjson; no dependency was added.

## Limits

- Geometry output still contains positions and triangle indices only; normals, UV vertex attributes, tangents and vertex colors from source are not imported.
- No glTF-to-`.astro-material` material asset creation, image AssetId registration, Scene material slot/override, Editor Inspector, texture decode/upload, PBR shader, lighting, shadows or Game View integration.
- Material extension payload is diagnosed but not fully preserved as structured data. Remote images are not fetched. Embedded images remain opaque source references and are not promoted to standalone files.
- Only Windows x64 Release was built and tested. Sanitizers/fuzzing and macOS/mobile validation were not run.
