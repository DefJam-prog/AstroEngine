# 07.2ca — Scene View lighting equivalence and face-region smoke

## Scope

Completed the bounded 07.2ca acceptance follow-up for the Windows x64 BGFX/D3D11 lighting prototype. No Scene API, file format or third-party dependency changed.

## Changes

- Connected the existing project-owned Lambert color/textured programs and their normal/light uniforms to the Scene View target. The prior Scene View initialization passed only the unlit programs, so the 07.2bz red-pixel assertion could be satisfied by unrelated scene colors without exercising Scene View lighting.
- Replaced the directional-light smoke's shared editor scene with an isolated Scene View fixture: two double-sided planes with opposite facing normals and one red directional light. The smoke checks red pixels in the front-facing region and zero red pixels in the back-facing region.
- Added two no-light capture modes using the same geometry: the legacy unlit programs and the Lambert programs with zero enabled lights. The app writes only the Scene View viewport as top-down raw BGRA; the CMake smoke SHA-256 compares the files.
- Recorded the current Scene View shader color handling in `docs/3D_RENDERING.md`: vertex-color RGB is used as linear input and lit output RGB is encoded to sRGB; texture RGB is decoded from sRGB, multiplied by linear diffuse and encoded to sRGB. Scene View bakes project material factors into its cached base-color texture and passes a white shader factor. This documents current code behavior and is not a cross-backend contract.

## Limits

- The pixel thresholds and raw-crop equality are validated on the current Windows x64/D3D11 BGFX path only.
- The test compares exact output between the two no-light shader paths on the same host; it does not establish a portable GPU golden.
- Current shader color handling is implementation-specific, not a complete material color-management contract. PBR, ambient/environment lighting, shadows and additional backends remain out of scope.
- The repository already had extensive user/stage changes in the working tree before 07.2ca. No reset, cleanup, commit or push was performed.
