# 07.2cg — framebuffer readback matrix for materials and alpha

## Goal

Extend the 07.2cf BGFX attachment-to-Editor-window check to representative material and alpha paths while keeping it smoke-only and scoped to the viewport under test.

## Changes

- General Editor smoke checks the Scene View BLEND fixture.
- Scene View equal-cutoff smoke checks a MASK material.
- Runtime Game View texture, MASK and four mip min-filter smoke cases check their Game View output. The unrelated Scene View is reported as not checked for these tests.
- CMake smoke scripts require and print the Game View readback metrics for texture/MASK cases; existing directional no-light script keeps its two-view assertion.
- No Scene/runtime API, file format, authored game resource or third-party dependency changed.

## D3D11 observations and acceptance

Samples are a 32×24 grid in the viewport interior. RGB channels have an 8/255 match tolerance. Current Windows x64 BGFX D3D11 fixture thresholds are 99.5% for no-light and Game View cases and 98.5% for Scene alpha fixtures.

| Scenario | Matches | Maximum channel delta | Result |
|---|---:|---:|---|
| Directional no-light legacy, Scene | 768/768 | 0 | pass |
| Directional no-light legacy, Game | 768/768 | 0 | pass |
| Directional no-light zero-light shader, Scene | 768/768 | 0 | pass |
| Directional no-light zero-light shader, Game | 768/768 | 0 | pass |
| Runtime Game View project/source texture | 768/768 | 0 | pass |
| Runtime Game View MASK | 767/768 | 56 | pass |
| Runtime Game View mip filters 9984/9985/9986/9987 | 768/768 each | 0 | pass |
| Scene View BLEND | 762/768 | 39 | pass at 98.5% |
| Scene View MASK equal cutoff | 758/768 | 108 | pass at 98.5% |

The alpha-case outlier samples remain in the denominator and their maximum delta is reported. Their specific source has not been classified; do not interpret the empirical Scene alpha threshold as proof of correct blend color or as a portable golden. No Vulkan/Metal/mobile backend was available in this run.
