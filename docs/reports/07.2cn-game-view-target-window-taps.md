# 07.2cn — Vulkan Game View target/window tap diagnostics

## Scope

Add opt-in instrumentation to the existing Vulkan Game View framebuffer-readback smoke. This stage does not modify production rendering, backend selection, public APIs, or the 99.5% readback requirement.

## Measurements

On the current Windows x64 host with AMD Radeon Graphics and Vulkan:

- BGFX Game View target: **624×416**.
- BGFX backbuffer: **1100×720**.
- Final-window TGA screenshot: **1280×800**.
- Measured Game View rectangle in screenshot: origin `(288,217)`, size **726×462**.
- BGFX `originBottomLeft`: **0** (`uvFlipY=0`).
- 32×24 grid matches: **563/768**, max channel delta **145/255**; vertically inverted alternate: **564/768**, max delta **185/255**.
- Per-row match counts, normal orientation: `27,27,27,27,27,27,27,26,26,23,23,20,22,23,22,27,27,27,27,27,27,27,0,0`.
- Five fixed target/window BGRA probes were emitted. First/top-left and center probes match (`102,86,75`); the top-right and bottom-left/right pairs include window values `(38,38,38)` against target `(102,86,75)`.

The screenshot dimensions differ from both the BGFX backbuffer and SDL-reported window pixel dimensions (1100×720, density 1). Those values are recorded, not reconciled by this diagnostic; coordinate mapping or capture scaling may affect interpretation. The row counts show concentration at the final two sampled rows, but do not prove the cause. No renderer correction is accepted based on this evidence.

## Reproduction

```powershell
$vsDevCmd='C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat'
& cmd.exe /d /s /c "call `"$vsDevCmd`" -arch=x64 -host_arch=x64 >nul && cmake --build build/07.2d-release-clean --config Release --target astro_editor --parallel 8"
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1 -R "^(editor\.runtime_bgfx_vulkan_game_view\.tap\.smoke|editor\.runtime_bgfx_vulkan_game_view\.texture\.smoke)$"
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1
```

The probe is enabled only by `ASTRO_VULKAN_GAME_VIEW_TAP_SMOKE=1` and is exercised through `editor.runtime_bgfx_vulkan_game_view.tap.smoke`. It is diagnostic data, not a Vulkan visual parity test.
