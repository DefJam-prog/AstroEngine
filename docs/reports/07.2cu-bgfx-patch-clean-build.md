## Scope

Verify that the tracked Vulkan resize patch applies and compiles against a clean staged checkout of the pinned BGFX dependency, without overwriting the existing dependency cache. A second Vulkan computer was not available, so this substage does not claim cross-driver portability.

## Limitations and next step

The clean copy validates patch application and Release compilation, not execution of an Editor linked to that separate library. The existing Editor smoke uses the already patched local BGFX library and passed on this same Windows x64 AMD Vulkan machine. The fixed-surface behavior therefore remains verified on one driver only. The clean build used generated MSBuild projects from the same pinned BGFX source revision; the unavailable generator itself was not exercised.

Recommended next substage: obtain a run on a second Vulkan host/driver and compare the same fixed-size/grow/shrink captures. If no second host can be connected, keep Vulkan support opt-in and document that the patch is host-validated rather than portable. No next substage was started.
