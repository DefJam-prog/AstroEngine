## Repeated verification

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1 --repeat until-fail:5 -R "^(editor\.runtime_bgfx_vulkan_game_view\.texture\.smoke|editor\.runtime_bgfx_vulkan_game_view\.tap\.smoke|editor\.runtime_bgfx_vulkan_game_view\.tap\.1280x800\.smoke)$"
ctest --test-dir build/07.2d-release-clean -C Release -V --output-on-failure --parallel 1 -R "^editor\.runtime_bgfx_vulkan_game_view\.tap\.smoke$"
```

The three tests each passed five consecutive launches: **15/15 executions, 0 failures, 0 skips**, total 58.76 s. The tap run exercises stable 1100×720, grows to 1280×800, then shrinks to 1100×720. Its nine screenshots on the verbose run were: one 1100×720 baseline, four 1280×800 grow frames, and four 1100×720 shrink frames. Readback was **768/768**, maxDelta **0**, meeting the 99.5% threshold. The separate fixed-1280×800 smoke and texture smoke also passed all five repeats.

The full 118-test suite was not rerun: this substage changed no production/test source, and the latest full Release run from 07.2ct was **117 passed, 0 failed, 1 mixed-DPI skip**. Build and focused tests were already verified before repetition.
