# 07.2d0 — Light Inspector pointer smoke

## Scope

Automate an actual pointer click on the `Apply` button for `PointLight3D` and `DirectionalLight3D`. The existing Inspector implementation and typed command API remain unchanged. The harness uses a fixed-position, uniquely identified no-docking ImGui window so its target does not depend on the saved dock layout.

For each applicable smoke, the harness seeds a changed draft, measures the visible Apply button, queues a left-button down/up pair, and verifies the component value changed through the Inspector's existing `light3d.set_point` or `light3d.set_directional` command. It then undoes the edit(s), confirms fixture values are restored, and clears only the test command history and dirty flag. Existing light rendering and command history checks remain enabled.

## Changed files

- `editor/main.cpp` — Apply-button geometry/click state and deterministic pointer smoke harness with command/Undo assertions.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/TESTING.md` — scope, decision, usage and results.
- `docs/reports/07.2d0-light-inspector-pointer-smoke.md` — this report.

No scene schema, public API, dependency, or CMake target changed. No user asset was edited.

## Verification

Build command, run from the x64 Visual Studio Developer environment:

```powershell
cmake --build build/07.2d-release-clean --config Release --target astro_editor astro_editor_localization_tests --parallel 4
```

Result: succeeded. MSVC emitted three existing C4189 warnings for unused C# metadata-validation smoke variables; linking completed.

Focused test command:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1 -R "editor\.(localization\.unit|runtime_bgfx_directional_light\.smoke|runtime_bgfx_point_light\.smoke)$"
```

Result: **3/3 passed in 10.27 s**. Both lighting smokes passed the new UI click, command effect, Undo restoration, and their existing rendered-light checks.

Full regression command:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1
```

Result: **119 passed, 0 failed, 1 skipped of 120 in 196.27 s**. `editor.window_mixed_dpi.sdl.smoke` was skipped because the available machine does not provide a pair of displays with distinct scaling.

## Limits

Evidence is from one Windows x64/MSVC Release environment using the currently available D3D11 adapter. It does not establish input behavior on macOS/Linux or other GPU/driver combinations. Checkbox and slider dragging are not part of this substage.
