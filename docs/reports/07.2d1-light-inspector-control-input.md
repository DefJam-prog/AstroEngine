# 07.2d1 — Light Inspector checkbox and intensity drag

## Scope

Extend the 07.2d0 pointer smoke to change actual point and directional light Inspector widgets. The harness begins with drafts matching the Scene components, clicks Enabled, drags the intensity slider from 25% to 75% of its measured track, and then clicks Apply. It checks that each widget changed its local draft and that the typed command applied those values to the component. Undo restores both the original intensity and enabled state before the test continues.

The test runs in the fixed, uniquely identified no-docking ImGui window established in 07.2d0. It reuses the current SDL-to-ImGui input queue, command registry, and Undo history. No product API, Scene schema, dependency, or user asset changed.

## Verification

Build in an x64 Visual Studio Developer environment:

```powershell
cmake --build build/07.2d-release-clean --config Release --target astro_editor astro_editor_localization_tests --parallel 4
```

Result: successful Release build. MSVC emitted three existing C4189 warnings for unused C# metadata-validation smoke variables; linking completed.

Focused regression:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1 -R "editor\.(localization\.unit|runtime_bgfx_directional_light\.smoke|runtime_bgfx_point_light\.smoke)$"
```

Result: **3/3 passed in 8.95 s**. Both light smokes performed the checkbox toggle, slider drag, Apply, command-value assertions, and Undo restoration, while existing Scene/Game light rendering checks remained active.

Full regression:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1
```

Result: **119 passed, 0 failed, 1 skipped of 120 in 255.27 s**. `editor.window_mixed_dpi.sdl.smoke` was skipped because the host does not provide two displays with distinct scaling.

## Limits

Evidence is from one Windows x64/MSVC Release environment with the available D3D11 adapter. macOS/Linux and other GPU/driver combinations were not tested. RGB color-slider pointer coverage was completed in 07.2d2.

## Recommended next substage

07.2d2 completed the RGB pointer interaction and Apply/Undo assertions. Recommend reviewing the combined light Inspector flow for keyboard/gamepad accessibility in a separately scoped substage; do not infer that pointer coverage validates those input methods.
