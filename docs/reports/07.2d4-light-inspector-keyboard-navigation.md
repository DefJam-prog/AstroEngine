# 07.2d4 — Light Inspector keyboard navigation smoke

## Scope

Add focused keyboard navigation evidence for the existing PointLight3D and DirectionalLight3D Inspector. This substage changes the smoke harness only; it does not add a new runtime input path, command, scene property, dependency, or editor setting.

## Behavior verified

- Synthetic Tab input reaches the light Inspector Enabled checkbox and intensity slider.
- Synthetic Enter toggles Enabled in the Inspector draft.
- The Scene component retains its baseline values before Apply, confirming that draft editing does not mutate Scene state directly.
- The existing point and directional rendering checks continue to run.

The harness uses `ImGuiIO::AddKeyEvent` after the SDL backend setup. It bypasses SDL key-event delivery and physical keyboard hardware. The passing result therefore verifies ImGui navigation and draft behavior, not end-to-end keyboard support.

## Not verified

- Physical keyboard or SDL-delivered key events through the Editor window.
- Numeric editing of RGB or intensity sliders by keyboard.
- Activating Apply/Undo with the keyboard.
- Editor gamepad navigation or disconnect behavior.
- Non-Windows platforms and graphics backends other than D3D11.

## Build and tests

Build from an x64 Visual Studio Developer environment:

```powershell
cmake --build build/07.2d-release-clean --config Release --target astro_editor astro_editor_localization_tests --parallel 4
```

Build result: succeeded. MSVC reported three pre-existing C4189 unused-variable warnings in the C# metadata smoke path.

Focused regression:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1 -R "editor\.(localization\.unit|runtime_bgfx_directional_light\.smoke|runtime_bgfx_point_light\.smoke)$"
```

Result: **3/3 passed in 9.80 s**.

Full Release regression:

```powershell
ctest --test-dir build/07.2d-release-clean -C Release --output-on-failure --parallel 1
```

Result: **119 passed, 0 failed, 1 skipped of 120 in 187.25 s**. The only skipped test was `editor.window_mixed_dpi.sdl.smoke`, which requires two displays with different scale settings; such a pair was unavailable on this host.
