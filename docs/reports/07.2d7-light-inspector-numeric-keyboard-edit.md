# 07.2d7 — Numeric keyboard editing for light Inspector intensity

## Scope and result

Add a localized numeric intensity field for PointLight3D and DirectionalLight3D while preserving the existing sliders and typed Apply commands. SDL smoke now enters `5.25` through the real SDL text-event path, confirms that the Inspector draft changes, and confirms that the Scene component stays unchanged before Apply.

The focused smoke does not claim keyboard activation of Apply or keyboard-only Apply/Undo. The existing pointer and command-history checks continue to cover Apply, Undo, and Redo. Physical keyboard hardware was not checked.

## Changes

- Added a localized `InputFloat` beside the existing intensity sliders.
- Extended Russian localization unit coverage for the numeric field label.
- Added PointLight3D and DirectionalLight3D SDL smoke coverage for text entry, changed draft, and unchanged Scene data before Apply.
- Kept separate observations for the smoke Inspector window and the regular docked Inspector so drawing the second view cannot overwrite the input state the smoke is checking.

No Scene schema, typed command API, renderer behavior, or external dependency changed.

## Build and focused tests

The regular Release `astro_editor.exe` was held open by an Editor window and was left untouched. Validation used the isolated tree `build/07.2d7-isolated` and cached dependencies/.NET SDK.

Build all Release targets:

```powershell
cmd.exe /d /s /c 'call "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\Tools\VsDevCmd.bat" -arch=x64 && cmake --build build/07.2d7-isolated --config Release --parallel 4'
```

Focused regression:

```powershell
ctest --test-dir build/07.2d7-isolated -C Release --output-on-failure --parallel 1 -R "editor\.runtime_bgfx_(point|directional)_light\.smoke$|editor\.localization\.unit$"
```

Result: **3/3 passed** (PointLight smoke, DirectionalLight smoke, localization unit). Both light smoke paths report an edited draft and unchanged Scene data before Apply.

The build emitted three existing MSVC C4189 warnings for unused C# metadata smoke locals. The final build completed successfully.

## Full Release regression

```powershell
ctest --test-dir build/07.2d7-isolated -C Release --output-on-failure --parallel 1
```

Result: **117 passed, 2 failed, 1 skipped of 120 in 142.76 s**. `editor.window_mixed_dpi.sdl.smoke` was skipped because this host has no suitable pair of differently scaled displays.

The failures were `editor.runtime_bgfx_vulkan_game_view.tap.smoke` and `.tap.resize_stress.smoke`, both reporting a Vulkan screenshot extent that did not match the expected window size immediately after a resize. On focused rerun, the non-stress tap test passed and the resize-stress test failed again on its frame-19 capture; later captures reported the requested extent. These resize failures are unrelated to the light Inspector changes and remain unresolved.

## Verification boundaries

- Confirmed: SDL text input changes the PointLight3D and DirectionalLight3D Inspector draft to `5.25`.
- Confirmed: the Scene model remains unchanged until Apply.
- Existing coverage: pointer-driven Apply plus command-history Undo/Redo.
- Not confirmed: keyboard activation of Apply, keyboard-only Apply/Undo, physical keyboard input, other operating systems or GPU vendors.
- Known regression issue: Vulkan resize screenshot timing, with two failures in the full suite and one repeated stress failure.
