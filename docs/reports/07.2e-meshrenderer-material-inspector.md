# 07.2e — MeshRenderer material Inspector

## Scope

Add a user-facing Scene Inspector for the 07.2d MeshRenderer material override. Only project materials already registered in AssetRegistry may be selected. Assignment and reset use the existing transactional command. PBR parameter editing and GPU material rendering remain out of scope.

## Implementation

- Inspector now shows mesh/primitive selection, the imported glTF source material index, and the independent project Material override.
- The choice list comes from `AssetRegistry::materialEntries`. It includes “Use source material” to clear the override. A selected material is resolved again immediately before the typed command executes, so changed or corrupt files are not silently applied.
- Missing, unregistered, stale, malformed, or invalid source references show diagnostic text and remain unchanged.
- Importer and AssetRegistry validation is cached by selected Scene/component/project. The user can request a new check with **Refresh material slot**; source files are not reread every Editor frame.
- Added English/Russian UI labels and formatted source-slot translation coverage.
- Editor smoke generates an isolated glTF fixture with a source material and registers a temporary project material. It verifies the Inspector, source slot, registered choices, and preserves the pre-existing 3D mesh visual/submission criteria.

## Limitations and next step

This Inspector does not edit material factors or texture assignments, upload textures, render PBR materials, or display the effective material in Scene/Game View. Source slot data is refreshed on selection change or explicit Refresh, so external file changes are not monitored continuously. Next recommended substage: **07.2f — evaluate and prototype the first 3D material draw path**, beginning with a bounded vertex/material contract and an independent BGFX smoke. Lighting and shadows remain separate work.
