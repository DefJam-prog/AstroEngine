# 07.2f — первый ограниченный BGFX material draw path

## Результат

Проверен узкий поток данных: Scene v7 `MeshRenderer` → project material override → AssetRegistry resolve → `MaterialAssetData.baseColorFactor` → умножение существующего vertex color → BGFX vertex buffer → D3D11 draw → screenshot readback. Добавлен отдельный `runtime.render3d.material.bgfx.smoke`; существующий Scene smoke также продолжает проходить с fixture Scene/material.

Контракт текущего прототипа: position + 8-bit vertex color и один линейный base-color factor, компонентно умножаемый в CPU в байтовом представлении. Изображение проверяется по foreground coverage, bounds и краснодоминантным пикселям. Это smoke threshold, не эталонный кадр и не полноценная модель цветового пространства.

## Ограничения

- Это отдельный sample, не Editor Scene View/Game View и не runtime-путь.
- BGFX pass использует существующий vertex-color shader; PBR не реализован.
- glTF importer по-прежнему принимает POSITION и индексы и отклоняет NORMAL/TEXCOORD и прочие дополнительные атрибуты.
- Нет texture decode/upload/sampling, metallic/roughness/emissive/alpha behavior, света, теней, color-managed вывода или платформ кроме Windows D3D11.
- Screenshot проверка пороговая и не задаёт производительный или визуальный бюджет.
