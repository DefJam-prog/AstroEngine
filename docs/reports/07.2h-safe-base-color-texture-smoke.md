# 07.2h — bounded base-color texture smoke

## Scope

Prove one end-to-end Windows prototype path from a registered image asset and material texture role to UV0 sampling in a BGFX D3D11 screenshot. This stage does not integrate material textures into Editor Scene/Game View and does not implement general PBR.

## Implementation

- Extracted `decodeWicImage` as a shared Windows WIC decode operation. It returns tightly packed BGRA8 and rejects zero dimensions, width/height over 16,384, images over 16 Mi pixels and byte payloads beyond the WIC copy limit. Existing SDL image texture creation now consumes the same decoded result.
- Added a test-owned 4×4 RGBA PNG with red/green/blue/yellow quadrants, a glTF triangle carrying TEXCOORD_0, and a separate material/Scene fixture binding `BASE_COLOR` AssetId 2 to UV channel 0.
- Added `--texture-smoke` to the optional Windows BGFX sample. It imports the image with AssetRegistry, resolves the material override and image from the content-addressed cache, verifies UV0 availability and role/channel mapping, uploads BGRA8, and samples it with the already staged BGFX texture shader binaries.
- Added WIC decoder integration coverage for cache decode, exact dimensions and representative BGRA texels, plus corrupt and missing inputs. Added a separate BGFX smoke requiring broad screenshot coverage and multiple sampled color families.
- Kept the existing scene and flat `baseColorFactor` material smokes intact. The importer-off procedural cube build remains supported; the optional 3D sample now ensures the backend-neutral render3d target is also configured when only the BGFX smoke option requests it.
- No dependencies were installed or downloaded. Existing local BGFX/SDL/WIC components are used.

## Limits

- Windows x64/MSVC/WIC and BGFX Direct3D 11 only; no macOS or mobile test.
- No sRGB conversion or documented color-management result; no multiplication of `baseColorFactor` with the texture yet.
- No glTF sampler settings or texture transforms, other material texture roles, mipmapping policy, normal maps, PBR, lighting, or shadows.
- No Editor Scene View, Game View, runtime integration, exact image golden, fuzzing, sanitizer, or device loss test.
- Smoke uses a single triangle with identity Scene transform and an intentionally tiny fixture; it is a renderer proof, not a production texture system.
