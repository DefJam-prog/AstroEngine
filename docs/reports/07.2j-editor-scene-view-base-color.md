# 07.2j — base-color material override в Editor Scene View

## Объём

Подключён уже проверенный 07.2h/07.2i путь в Windows Editor Scene View для явного `MeshRenderer.materialOverride`. Геометрия Scene View теперь сохраняет UV0 рядом с позицией и vertex color. При корректном override Editor разрешает изображение через AssetRegistry, читает только `cachedPath`, использует ограниченный WIC decode, применяет общий `prepareLinearBaseColorBgra8` и отправляет временный BGRA8 linear texture в BGFX. Factor-only material получает временную белую 1×1 текстуру с тем же linear factor. Источники и AssetRegistry cache не переписываются.

Текстурный shader применяется для UV0 и корректного ресурса. Для отсутствующей/неразрешимой текстуры, UV набора кроме 0, отсутствующего UV0, ошибки WIC/factor validation или GPU upload остаётся vertex-color draw и отображается накопительный список диагностик. Чтобы не читать и хэшировать material file каждый кадр, его разрешённые значения хранятся в cache MeshRenderer; после ручного изменения material-файла требуется его повторная регистрация и **Reload 3D meshes**. GPU material texture освобождается вместе с preview mesh cache. CMake подключает WIC cache adapter при Windows Editor + glTF importer даже когда отдельный BGFX sample выключен.

## Smoke и пример

`astro_editor.exe --smoke` сам создаёт временный проект, glTF triangle, тестовое PNG, зарегистрированный textured material с фактором `(0.65, 0.60, 0.80, 1)`, и отдельный material с UV1 для fallback. Он проверяет draw/fallback counters, оба сообщения диагностики (пропавший model AssetId и base-color fallback), цветные base-color пиксели и ранее действовавшие белые mesh-пиксели, иерархический origin и Frame All.

Проверенный запуск на D3D11 сообщил: `lastFrameMeshSubmissions=2`, `lastFrameMeshDiagnostics=2`, `lastFrameTexturedMeshes=1`, `lastFrameMaterialFallbacks=1`, `missingAssetDiagnostic=1`, `baseColorFallbackDiagnostic=1`, `sceneViewWhitePixels=5501`, `sceneViewBaseColorPixels=7940`.

## Изменения и ограничения

Изменены `editor/main.cpp`, `editor/CMakeLists.txt`, `editor/Localization.cpp`, `engine/runtime/CMakeLists.txt` и `tests/unit/editor/LocalizationTests.cpp`; обновлены README, архитектурная заметка, дорожная карта, статус, журнал решений, руководство 3D и TESTING. Добавлен D142 и этот отчёт. Новых библиотек нет. Все изменения из предыдущих 07.2a–i уже находились в dirty working tree и оставлены на месте; коммита и GitHub push не было.

Поддерживается только явный project material override и роль base color; только Windows x64/D3D11 и UV0. glTF source material автоматически не назначается. Остальные роли, alpha modes/blending, glTF sampler и texture transforms, mipmaps, lighting, shadows и Game View не реализованы. CPU-преобразование использует 8-bit linear intermediate. Screenshot assertion проверяет наличие цветных пикселей с широким порогом, а не точную гамму/изображение на всех дисплеях и драйверах. Debug, macOS и другие backend не проверялись.
