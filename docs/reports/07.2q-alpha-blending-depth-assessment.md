- Scene View uses the copied BGFX `vs_stencil_texture` / `fs_stencil_texture` shader. The fragment shader returns sampled RGBA unchanged. The draw state writes RGB, alpha and depth, enables `DEPTH_TEST_LESS`, and has no alpha blend state or alpha test/discard.

## Rendering contract recommendation

glTF defines OPAQUE as ignoring alpha; MASK as binary coverage where alpha below cutoff is discarded and surviving samples write depth; BLEND as Porter-Duff over. The real-time note allows implementation choice for BLEND sorting/depth writes but specifically calls out depth buffers and sorting. See the [Khronos glTF 2.0 Alpha Coverage section](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#alpha-coverage).

For the first Editor Scene View implementation:

1. **OPAQUE:** ignore material/texture alpha, output alpha 1; no blending; depth test and writes enabled.
2. **MASK:** compute final base-color alpha as factor alpha times texture alpha, discard below `alphaCutoff`, output surviving fragments as fully opaque; no blending; depth test and writes enabled only for surviving fragments.
3. **BLEND:** use straight-alpha over (`srcRGB × srcA + dstRGB × (1 − srcA)`); depth-test against opaque/masked geometry, disable depth writes, and submit after those queues. When the color target's alpha is meaningful, use separate RGB/alpha blend factors so resulting alpha is `srcA + dstA × (1 − srcA)`.
4. Keep the view sequential and order the CPU draw items explicitly: opaque/mask first, blended items back-to-front by view-space object-center depth, stable EntityId tie-break. BGFX documents that `DepthDescending` sorts back-to-front, but a single depth-sort view cannot itself guarantee an opaque/mask pass before a transparent pass. See [BGFX draw-call sort modes](https://github.com/bkaradzic/bgfx/blob/master/docs/internals.rst#sort-based-draw-call-bucketing) and [blend-state definitions](https://github.com/bkaradzic/bgfx/blob/master/include/bgfx/defines.h).
5. Explicitly choose culling based on `doubleSided`; do not leave the stored value disconnected from renderer state. Decide separately whether alpha-aware mip generation is required before MASK/BLEND mip filtering is enabled.

This is an object-level approximation: it cannot correctly sort intersecting or self-overlapping transparent triangles. Order-independent transparency, per-triangle sorting, alpha-to-coverage and generalized PBR are deferred. Source image and project material data remain unchanged.
