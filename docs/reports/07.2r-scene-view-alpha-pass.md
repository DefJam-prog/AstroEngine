# 07.2r — bounded Scene View alpha pass

**Date:** 2026-11-18  
**Status:** completed, Windows x64 / MSVC Release / BGFX D3D11 only

## Scope

Implement the previously assessed OPAQUE, MASK and BLEND policy only in the Editor Scene View. Material and scene schemas, source image bytes and imported mesh geometry remain unchanged. No new third-party dependency was added.

## Implementation

- Added owned fragment shader sources for vertex-color and base-color texture paths. OPAQUE forces alpha to 1, MASK discards when sampled alpha is below cutoff, and BLEND returns straight-alpha color for Porter-Duff over.
- CMake builds those fragment shaders to D3D11 DXBC using the already staged BGFX `shaderc`. CMake does not fetch the tool. `docs/BUILD_GUIDE.md` records the local generation/build commands and output location.
- Kept the BGFX view sequential and explicitly sorts draw items OPAQUE -> MASK -> BLEND. BLEND uses camera-space object-center Z for far-to-near sorting and stable EntityId ties. Invalid depth values map to a stable zero-depth key.
- OPAQUE and MASK depth-write; BLEND depth-tests without depth writes. RGB and alpha use separate straight-alpha factors. Single-sided materials request clockwise culling; `doubleSided` disables it.
- MASK/BLEND do not generate mip chains until alpha-aware filtering exists. This avoids coverage shifts and color fringes from the current straight-RGB/alpha downsampler, at the cost of distant minification quality.
- Added pure sorting unit tests and expanded the existing D3D11 Editor smoke with three queues, a half-alpha source material and a below-cutoff MASK mesh in front of a blended triangle. The screenshot confirms that the discarded mask does not occlude the BLEND draw; OPAQUE material factor alpha is below one.

## Known limits

The Editor-only pixel smoke checks a broad color range, not a full-image golden. Cutoff-at-equality and above-cutoff rendering are not separately asserted by screenshot. Object-center sorting cannot fix intersecting/self-overlapping transparent triangles. MASK/BLEND mipmapped materials use only their base mip until an alpha-aware policy is added. Game View, other platforms/backends, OIT, all other PBR roles, lighting and shadows remain outside scope.
