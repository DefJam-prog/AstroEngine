# 07.2t — Rendered MASK cutoff boundary smoke

## Scope

Added three Windows Editor command-line smoke modes for the MASK shader's strict alpha cutoff boundary. Each runs the existing disposable Scene View project using D3D11, makes the MASK test material diagnostic magenta, renders a screenshot, and classifies magenta pixels only inside the normalized Scene View crop.

The cases set material alpha to 0.49, 0.50 and 0.51 with cutoff 0.50. The below case requires fewer than 8 magenta pixels and retains the prior cyan-under-mask blend assertion. Equality and above require at least 32 magenta pixels. The screenshot classifier uses broad thresholds that accept the observed sRGB swapchain result around RGB (149,19,149); the renderer cutoff/shader was not changed.

## Results

Verbose smoke metrics:

| Material alpha | Cutoff | Magenta pixels in Scene View crop | Result |
| ---: | ---: | ---: | --- |
| 0.49 | 0.50 | 0 | discarded |
| 0.50 | 0.50 | 702 | retained at equality |
| 0.51 | 0.50 | 702 | retained above cutoff |

The existing below-cutoff overlap measured 550 cyan blend pixels in that run. The first implementation attempt had no qualifying pixels for equality/above because the screenshot detector required each color channel to be at least 160; inspection showed the actual sRGB magenta was about (149,19,149). Lowering only the detector threshold resolved the false negative. All three focused tests then passed **3/3 in 8.46 s**.

Windows 11 x64/MSVC Release baseline build reported no work; baseline full CTest passed **59/59 in 18.16 s**. Final build succeeded. Final full CTest passed **62/62 in 27.45 s**. Commands:

```powershell
cmake --build build/07.2d-release-clean --parallel 8
ctest --test-dir build/07.2d-release-clean -V -R '^editor\.scene_view_mask_cutoff\.'
ctest --test-dir build/07.2d-release-clean --parallel 1 --output-on-failure
```

Logs: `build/07.2t-prechange-build.log`, `build/07.2t-prechange-ctest.log`, `build/07.2t-boundary-build.log`, `build/07.2t-boundary-ctest.log`, `build/07.2t-final-ctest.log`.

## Files and limits

Changed the Editor smoke parser/render check and CTest registration, plus README and the stage status, roadmap, decision, rendering, and testing documents. No renderer shader behavior, public scene/material API, user assets, or dependencies changed. The smoke validates factor-only 1×1 texture samples on this Windows D3D11 host; arbitrary source-image alpha distributions, other GPU drivers/backends, and cross-platform image parity remain untested. The magenta pixel check is a coarse localized assertion, not an image golden.
