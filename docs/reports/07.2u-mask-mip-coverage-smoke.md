# 07.2u — Nonuniform MASK alpha mip smoke

## Scope

Added a disposable Editor D3D11 smoke fixture that generates and imports a 64×64 magenta RGBA PNG. RGB is constant; alpha is opaque on the left half and transparent on the right. The test binds the image to the existing Scene View MASK object with cutoff 0.5, Repeat wrapping, `LinearMipmapLinear`, and two UV U scales (2 and 4). No checked-in or user image is modified.

Each run verifies that the MASK draw submitted a texture with mip levels and that the normalized Scene View crop contains a broad, partial number of magenta pixels plus visible underlying translucent blend pixels. The partial coverage range is 100–650 pixels; this tolerates raster/filter differences while rejecting fully missing or fully solid coverage.

## Limits

Both test materials request mipmapped filtering and the Scene View reports a mipmapped MASK texture submission. The test does not query hardware's exact selected LOD; UV scale changes the minification pressure. It covers this deterministic split pattern and current D3D11 driver only, not arbitrary texture alpha fields, other GPUs/backends, or a cross-platform golden. No source asset, file format, dependency, shader policy, or renderer API changed.
