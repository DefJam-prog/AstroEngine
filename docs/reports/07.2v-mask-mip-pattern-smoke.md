# 07.2v — Additional MASK alpha mip smoke patterns

## Implemented

Extended the isolated Scene View MASK mip smoke PNG generator with two alpha shapes: a checker of opaque/transparent 16×16 blocks (50% source coverage), and a centered 32×32 transparent hole in a 64×64 opaque field (75% source coverage). Kept the earlier vertical split runs at UV U scales 2 and 4. Checker runs at U scale 2; center-hole runs at U scale 4. Each material uses MASK cutoff 0.5, Repeat and trilinear mip sampling. Tests verify a MASK mip texture submission, partial magenta coverage in the Scene View crop, and visible blend pixels through discarded texels. All generated PNG files are placed only in disposable smoke projects.

## Findings and limits

An initial 4×4 checker at U scale 4 collapsed to a uniform-alpha sampled mip and produced zero mask pixels. At that small mip size the 50% target is not representable by the discrete texel count, so the coverage policy selected an endpoint. The final fixture uses larger blocks and a lower checker scale so a mixed mip coverage can be tested. This demonstrates one limitation of coverage preservation rather than a general failure of the coverage algorithm.

The tests confirm MASK mip upload and visible patterns on this Windows D3D11 path. They do not query the exact GPU-selected LOD, validate arbitrary authored images, or establish parity on other drivers/platforms. No renderer shader, material schema, source asset, dependency or public API changed.
