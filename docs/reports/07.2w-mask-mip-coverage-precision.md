# 07.2w — MASK mip coverage precision

## Scope

Evaluate cutoff coverage for every CPU-generated MASK mip across split, checker and center-hole alpha images at 64×64 and odd 31×17 source sizes. This substage does not change rendering APIs, material/scene formats, the area filter, GPU shaders or dependencies. The test verifies preparation results and confirms source image bytes remain unchanged.

## Finding and change

The former 24-step binary search could stop on the wrong side of an 8-bit alpha quantization boundary. For the 31×17 checker, mip 3×2 produced 4/6 covered texels although 3/6 was achievable and closer to the source's 50.2846% coverage. Replaced that search with a finite scan of the 256 possible passing alpha-byte thresholds for each source alpha bin. Candidate scoring and mip output now use the same UNORM8 conversion. The first passing alpha byte is found using the exact cutoff comparison, including cutoff edge values.

An independent unit oracle enumerates threshold outcomes from the unadjusted mip chain and verifies every adjusted level is nearest-achievable. The formerly failing 3×2 checker now has 3/6 coverage (50%). For 64×64 split/checker levels through 2×2, and center-hole levels through 4×4, measured coverage matches exactly. Odd-sized fixtures quantize to their nearest available fraction (examples: split 15×8, 46.667% vs 48.387% target; center-hole 15×8, 76.667% vs 75.712% target). The worst absolute difference is 50 percentage points for a 1×1 mip whose binary coverage can only be 0% or 100%; some 2×2 cases also cannot match the target exactly.

## Limits

This establishes that the CPU selector chooses the closest representable fraction for these fixtures and supported cutoff semantics. It does not prove exact preservation for arbitrary image histograms, sample-level GPU coverage, hardware LOD choice or cross-backend behavior. At very small mip dimensions, quantization is inherent; choosing the nearest value cannot preserve the source fraction exactly. Existing disposable D3D11 MASK pixel smokes remain the only visual GPU checks in this series.
