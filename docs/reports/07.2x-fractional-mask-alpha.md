# 07.2x — fractional-alpha MASK coverage sweep

## Scope

Extend 07.2w's nearest-achievable mip coverage assessment from binary alpha to partially transparent inputs. The same CPU preparation path, cutoff semantics, data format and source-asset policy remain in use. This stage changes test coverage and documentation only; no runtime selector, API, schema or dependency changes were needed.

## Fixtures and findings

Added two deterministic source patterns: vertical alpha steps over `{0, 32, 64, 96, 128, 160, 192, 255}` and a horizontal 8-bit alpha ramp from 0 to 255. Each is checked at 64×64 and odd 31×17 dimensions with cutoffs 0.25, 0.50 and 0.75. Every generated mip is compared with an independent enumeration of the nearest coverage reachable through alpha scale and 8-bit quantization. Source bytes are checked unchanged before and after the cutoff sweep.

The selector chose the nearest attainable coverage for every tested mip/cutoff; no new counterexample was found. For example, the odd 31×17 ramp at cutoff 0.50 has target 48.387%; the 15×8 mip reaches 46.667% (nearest available in that fixture), while smaller levels are more coarsely quantized. The worst absolute delta remains 0.5 at a 1×1 level whose coverage can only be 0% or 100%.

## Limits

These tests verify CPU mip selection and the cutoff comparisons for the listed patterns and thresholds. They do not check GPU-selected LOD or provide visual goldens for each cutoff, arbitrary alpha distributions, other render backends or non-Windows platforms. Tiny mip levels cannot represent all source coverage ratios.
