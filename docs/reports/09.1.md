# Подэтап 09.1 — локальный AI Editor API

Дата: 2026-11-14.

## Изменения

- Добавлен `astro::core::AIEditorApi` версии 1.0 как in-process C++ фасад поверх `CommandRegistry`.
- Добавлен детерминированный каталог зарегистрированных команд с ID, версией, описанием, типизированными полями payload, типом результата и признаком транзакционности.
- Для Scene Model описаны только две существующие команды: `entity.set_property` и `entity.set_sprite_renderer`.
- Typed validation/execution делегируются общему registry, сохраняющему существующие валидаторы, audit trail, транзакции, Undo и Redo.
- Добавлен integration coverage фасада, версии API, содержимого/порядка каталога, метаданных и вызова команды.

## Проверки

Baseline до изменений:

```text
cmake --build build\stack-spike --parallel 4
  Passed (Ninja: no work to do)
ctest --test-dir build\stack-spike --output-on-failure -j 4
  42/42 passed, 7.45 s
```

После изменений:

```text
cmake --build build\stack-spike --target astro_scene_command_tests --parallel 4
  Passed, exit code 0
ctest --test-dir build\stack-spike -R "^scene\.command\.integration$" --output-on-failure
  1/1 passed, 1.01 s
```

Полная чистая Debug пересборка после обнаружения stale объектов в первой инкрементальной регрессии:

```text
cmake --build build\stack-spike --clean-first --parallel 4
  Passed; rebuilt 429 targets/actions including editor and tests
ctest --test-dir build\stack-spike --output-on-failure -j 4
  42/42 passed, 35.35 s
```

Первый инкрементальный полный прогон до полной пересборки дал 39/42: core command tests failed, а prefab integration и Editor smoke аварийно завершились. MSVC/Ninja конфигурация не пересобрала все потребители изменённого заголовка команды; после полного clean-first rebuild все три сбоя исчезли. Полная пересборка и повторный прогон — результаты, используемые для приёмки.

`git diff --check` прошёл. Git сообщил обычное предупреждение о преобразовании LF в CRLF для tracked-файлов на этой Windows-конфигурации; файлы не нормализовались и не переписывались массово.

## Ограничения

Это доверенный in-process typed API, не Codex adapter и не внешняя граница безопасности. JSON, wire protocol, динамический разбор payload, permissions, подтверждение рискованных действий, preview/diff, sandbox и остановка долгих операций не входят в 09.1. Новый endpoint не публиковался и внешние данные не отправлялись.
