# Подэтап 09.2 — локальный Codex context/plan adapter

Дата: 2026-11-23.

## Результат

Добавлена отдельная библиотека `astro_ai_editor` и `astro::ai::CodexProjectAdapter`. При включении API он возвращает детерминированную read-only копию переданной активной Scene: identity сцены, сущности/иерархию, Transform и известные типы компонентов с ID/schema version, а также каталог реально зарегистрированных команд.

Adapter проверяет описательный план версии 1: UTF-8 и ограничения размера текста, число шагов, уникальность ID, наличие команды в текущем каталоге и совпадение версии её схемы. Контекст и проверка плана не изменяют Scene. `CodexChangePlan` не содержит payload и не исполняется.

`ASTRO_BUILD_AI_EDITOR_API` по умолчанию выключен; модуль собирается при включённой опции или в test-конфигурации. Новых внешних зависимостей нет.

## Ограничения

- Adapter получает уже загруженный Scene; он не читает дерево файлов или все ресурсы проекта.
- План описательный: значения payload не представлены, typed validation/execution отсутствуют.
- Нет Codex process/JSON/IPC transport, естественно-языкового планирования, diff, разрешений, подтверждения, checkpoint или sandbox. API рассчитан на доверенный in-process caller и не является security boundary.
- Проверено только на Windows x64/MSVC Release в текущем конфиге; macOS/Linux не проверялись.
