# Подэтап 09.3a — read-only предпросмотр изменения свойства

Дата: 2026-11-23.

## Изменения

`CodexProjectAdapter::previewSetProperty` добавляет ограниченный preview для зарегистрированной transactional-команды `entity.set_property` v1. Adapter:

1. подтверждает, что команда зарегистрирована и версия схемы совпадает;
2. читает текущее typed значение из переданной Scene;
3. проверяет новое значение той же Scene Property schema;
4. возвращает Scene/Entity/property identity, typed before/after и `changesValue`.

Операция read-only. Она не исполняет команду и не записывает данные. Ошибки покрыты для устаревшей версии, отсутствующего entity и неизвестного свойства. Значения передаются как `PropertyValue`, поэтому не теряют тип из-за форматирования в текст.

## План, зависимости и риск

Использованы действующие `Scene::getProperty`, `Scene::validateProperty` и зарегистрированный command catalog. Новые зависимости и изменения Scene API/формата не потребовались.

Preview представляет снимок. Scene может измениться до будущего apply; любой путь применения обязан повторно сверять текущее значение и валидировать payload. Прямого пользовательского подтверждения в Editor пока нет, поэтому этот срез не применяет изменения и не выдаёт permission token.
