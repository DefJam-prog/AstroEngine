# 09.3c — SpriteRenderer visibility review

## Scope

The Editor's AI Change Review panel now previews changing visibility on an entity that already has a `SpriteRenderer`. Preview records the typed before/after visibility, Scene/Entity/Component identity and current texture AssetId without changing the Scene. Direct confirmation rechecks project and scene identities, Scene ID, component ID, texture AssetId and current visibility, then calls the existing transactional `entity.set_sprite_renderer` command. Normal validation and Undo/Redo remain in `CommandRegistry`.

This action does not create/remove a SpriteRenderer or select a replacement texture. It is a trusted in-process review flow, not an AI permission boundary, sandbox, external transport, or general rollback system.

## Tests

- `ai.codex_change_review.unit` covers read-only visibility preview, changed-project rejection, stale texture/component state, re-preview, texture preservation, transactional apply, Undo/Redo and cancellation. Existing property-review cases remain in the same unit target.
- `editor.ai_sprite_visibility_review.smoke` uses synthetic SDL/ImGui pointer events to activate Preview and Confirm. It verifies the diff, applies the change to the selected entity, saves and reloads the Scene, then checks that visibility changed while the selected SpriteRenderer's original AssetId remained intact.
- `editor.ai_change_review.smoke`, `scene.command.integration`, and `editor.localization.unit` provide name-review, existing command, and Russian UI regressions.
