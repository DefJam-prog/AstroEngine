

# 09.3l — Hierarchy drag/drop reparent

## Scope

Add single-entity drag/drop to the Editor Hierarchy and route both a new parent and Scene root through the existing transactional `entity.reparent` command. No next substage was started.

## Behavior

- Drag an entity row onto another entity row to reparent.
- Drag an entity onto the footer target **Scene root (drop here to unparent)** to clear its parent.
- Both paths invoke the registered command, mark the Scene dirty, retain local Transform, Transform ComponentId and descendant links, and use existing Undo/Redo history.
- Save and reload through the normal Scene workflow.
- Invalid/self/cyclic parent changes remain rejected by command validation.

Multi-select, world-pose-preserving reparent and manual physical-mouse validation are outside this slice.
