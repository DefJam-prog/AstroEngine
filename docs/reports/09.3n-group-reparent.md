# 09.3n — групповое переподчинение Hierarchy

## Результат

Реализованы Ctrl+Click множественное выделение в Hierarchy и перенос выбранных верхних корней на другого родителя либо в корень сцены. Для обычного клика по уже выбранной строке выбор сохраняется, пока пользователь начинает drag; если drag не начался, выбор схлопывается до одной строки. Shift-range selection не добавлялся.

Новая `entity.reparent_many` v1 принимает `entities: UnsignedIntegerArray` и `parent: UnsignedInteger`, где `0` обозначает корень. Существующая `entity.reparent` v1 не менялась. Команда удаляет дубликаты, не переносит отдельно выбранного потомка выбранного предка, проверяет целостность всей результирующей иерархии на копии Scene и только затем применяет изменения одной `CommandTransaction`. Пустой/неизвестный набор, отсутствующий Transform, неизвестная цель и цикл отклоняются до изменения live Scene. Если все корни уже имеют нужного родителя, запись Undo не создаётся.

Группа сохраняет local Transform, Transform ComponentId, порядок сущностей Scene и связи потомков. При смене родителя derived world pose может измениться. Sibling reordering и group Inspector не входят в этот срез.

## Ограничения

Оконный тест создаёт ввод через SDL/ImGui и проверяет production handler, но не заменяет ручную проверку физической мышью. macOS/Linux и другие платформы не запускались. Drag переносит только выбранные верхние корни; порядок соседей отдельно не меняется, групповое редактирование Inspector отсутствует. AI preview/permissions для группового действия не добавлялись.
