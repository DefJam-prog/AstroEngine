# 09.3r — сброс группового Transform draft при смене выделения

## Цель

Автоматически проверить UX-контракт Inspector: если пользователь меняет выделение с неприменённым групповым Transform draft, Inspector отбрасывает значение и показывает предупреждение; новое выделение получает свежий snapshot.

## Реализация

- Существующий `editor.hierarchy_multi_transform_inspector.smoke` теперь использует текущий набор выделенных сущностей Editor, а не постоянную пару fixture IDs.
- После проверок реального SDL-ввода и защиты stale draft smoke создаёт новый неприменённый draft и переводит выделение с двух объектов на один.
- Проверяются новый список выбранных сущностей, отсутствие draft override и выставленный UI-флаг, соответствующий показанному сообщению о сбросе.
- Тест возвращает два объекта в selection, убеждается в чистом состоянии, затем повторяет групповое Apply, проверку одной записи Undo, Undo/Redo, стабильности ComponentId и Scene save/reload.
- Команда `entity.set_transforms`, формат сцены и пользовательские игровые файлы не менялись.

## Ограничения и дальнейшая работа

Смена selection задаётся автоматически в Editor smoke, но ручное прохождение этого сценария мышью отдельно не выполнялось. Редактирование компонентов, кроме Transform, по группе всё ещё не реализовано. Следующий подэтап следует выбирать отдельно по ROADMAP и подтверждать перед началом.
