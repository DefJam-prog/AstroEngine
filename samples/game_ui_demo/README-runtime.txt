AstroEngine Game UI runtime prototype — Windows x64

Run astro_game_ui_demo.exe to open the current Game UI prototype.
The window demonstrates menu, gameplay HUD, pause, and settings screens.
The audio cues are synthesized at runtime and can be unavailable on systems
without a usable audio device; the prototype reports this and continues.

This package is a runtime UI prototype, not the completed 2D puzzle game.
It does not contain a visual puzzle board, authored game levels, or saved
player progression. The puzzle, save, and checkpoint APIs exist separately
in the engine source and are not connected to this demo executable yet.

Third-party license texts are in the licenses directory.
